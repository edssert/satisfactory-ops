# Satisfactory Ops 문서 허브

이 폴더는 `C:\Dev\satisfactory-ops` 안에 있는 별도 Obsidian 볼트다. `.obsidian`의 사용자 테마와
플러그인 설정은 문서 정리 대상이 아니다.

## 정본

| 문서 | 책임 |
|---|---|
| [[PRODUCT]] | 제품 범위, 기능 요구사항, 품질 기준, 완료 정의 |
| [[ENGINEERING]] | 프레임워크, 모듈, 데이터, 런타임과 검증 경계 |
| [[DESIGN]] | 시각 시스템, 테마, 모션, 랜딩과 편집기 표현 |
| [[ASSETS]] | 게임 자산, 탑뷰, 토대, 운송 자산과 승인 기준 |
| [[DECISIONS]] | 현재 유효한 기술·제품 결정 |
| [[ROADMAP]] | 작업 순서, 상태, 단계별 종료 조건 |
| [[README|연구 색인]] | 다시 검증한 외부 근거와 조사 대기열 |

## 문서 운영 규칙

1. 같은 사실을 둘 이상의 정본에 반복하지 않는다.
2. 새 정본을 만들지 않고 기존 여섯 문서 중 책임이 맞는 곳을 갱신한다.
3. Research에는 공식 원문, 표준, 논문, 원본 저장소 또는 버전이 확인된 게임 자료만 사용한다.
4. 속성은 Research의 `confidence`만 선택적으로 허용한다. 나머지는 파일명, H1과 Git 이력으로 관리한다.
5. 세션 로그, 에이전트별 조사 결과, 출처 채널별 노트는 만들지 않는다.
6. 구현이 바뀌면 같은 커밋에서 관련 정본과 [[ROADMAP]]을 갱신한다.
7. AI 에이전트는 이 파일에서 시작해 `PRODUCT → ENGINEERING/ DESIGN/ ASSETS → ROADMAP` 순서로 필요한
   정본만 읽는다. 폴더 전체를 선행 로드할 필요가 없어야 한다.
8. 요구사항과 결정에는 안정적인 ID를 사용하고, 상태는 [[ROADMAP]] 한 곳에서만 관리한다.
9. 문서의 명령, 경로, 스키마 이름은 복사해 실행할 수 있는 실제 값으로 쓴다.
