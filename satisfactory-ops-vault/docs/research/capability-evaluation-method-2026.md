# 기술·지식·스킬 평가 방법

이 문서는 Satisfactory Ops 전면 개편에 사용할 기술, 산업 지식, 게임 자료, Codex 스킬을 같은 기준으로
조사하고 점수화하는 방법을 정의한다. 구현 비용, 작업 시간, 토큰 사용량은 평가 점수에 포함하지 않는다.
고품질 결과에 기여할 가능성이 있는 후보를 조사 전에 임의로 제외하지 않는다.

## 1. 평가 대상

다음 대상은 모두 동일한 증거 계약을 적용한다.

- 프레임워크, UI·캔버스·그래프·상태·저장·검색·내보내기 라이브러리
- GSAP 플러그인, WebGL·SVG·Canvas·Worker·WASM 등 브라우저 기술
- 생산 최적화, 시설 배치, 직교 라우팅, 공정 도면, 인간공학 관련 논문·표준·알고리즘
- 게임 설치본, 공식 문서, 실제 세이브·블루프린트, AndersPottemager 원본 자산
- Codex 전역 스킬, 저장소 전용 검사 스킬, 필요한 신규 스킬

## 2. 증거 계약

후보별 평가는 다음을 모두 기록한다.

1. 공식 문서·원 논문·표준·원본 저장소 URL
2. 접근일, 현재 버전, 최근 릴리스 또는 커밋 활동
3. 저장소 별 수와 이슈·릴리스 상태. 별 수만으로 채택하지 않지만 반드시 기록한다
4. 라이선스·유료 조건·자산 사용 근거. 비용은 감점하지 않고 필요한 조건을 충족한다
5. Satisfactory Ops의 실제 데이터와 자산을 사용한 파일럿
6. 비교 기준선과 동일 과업의 정량·정성 결과
7. 실패 조건, 불확실성, 재검증 조건

검색 결과 요약과 2차 블로그만으로 점수를 확정하지 않는다. 기술 후보는 공식 문서와 원본 저장소를, 게임
사실은 설치본과 공식 자료를, 공법은 원 논문·표준과 실제 게임 표본을 우선한다.

점수는 근거 문서와 파일럿 결과가 없는 항목을 0점으로 둔다. 추정 점수로 채우지 않는다.

### 3.1 단일 점수의 한계와 다축 운영

위 100점은 제품 적합성을 비교하는 기존 기준선이다. 비용·복잡성을 이 점수에서 빼면 고성능이지만 어려운
기술이 과소평가되므로 실제 능력 수집과 실행 순서는 다음 다섯 축을 별도로 기록한다.

| 축 | 주요 구성 | 용도 |
|---|---|---|
| 결과 가치 100 | 최종 품질 25, 도메인 정확성 20, 측정 성능 20, 능력 범위 15, 결합·재사용 10, 검증성 10 | 성능·품질 중심 기술 가치 |
| 증거 신뢰도 100 | 원문·출처 20, 최신성·호환 15, 실제 표본 파일럿 30, 동등 과업 비교 20, 결정적 회귀 15 | 추정과 검증된 능력 분리 |
| 복잡성 부담 100 | 알고리즘 20, 통합 20, 운영·컴퓨팅 15, 업데이트 20, 보안·법·마이그레이션 15, 전문지식 10 | 필요한 시간·토큰·비용·유지보수 배정 |
| 흡수 레버리지 100 | 다도메인 재사용 30, 헤드리스 자동화 25, 능력 단위 분해 20, 다른 도구 증폭 15, 자가개선 10 | 한 번의 투자가 여러 작업을 개선하는 정도 |
| 조사 배분 100 | 복잡성 30%, 불확실성 25%, 영향 반경 20%, 새로움 15%, 변화 속도 10% | 조사 깊이와 재검토 주기 |

복잡성 부담은 감점이 아니라 **투입 자원 지시값**이다. 조사 배분은
`0.30×복잡성 + 0.25×(100-증거) + 0.20×영향반경 + 0.15×새로움 + 0.10×변화속도`로 계산하고,
후보별 실제 조사 몫은 `조사 배분×결과 가치`에 비례시킨다. 파일럿 순서는
`0.55×결과 가치 + 0.20×흡수 레버리지 + 0.15×증거 + 0.10×긴급성`으로 정하며 복잡성을 빼지 않는다.
성능·품질이 사실상 같은 대안 사이에서만 낮은 부담을 우선한다.

변화 속도 75 이상은 매주, 50~74는 매월, 25~49는 분기, 24 이하는 주요 런타임·게임 버전 변경 때
레이더가 다시 확인한다.

### 3.2 능력 단위 흡수

저장소 하나를 채택/기각하는 대신 한 후보에서 `install`, `integrate`, `adapt-code`, `adapt-pattern`,
`data`, `test`, `reference`, `monitor` 형태의 능력을 여러 건 추출한다. 낮은 전체 점수, 낮은 별 수,
중복, 비용, 낯섦은 능력 폐기 사유가 아니다. 데이터 손실, 비밀·사용자 데이터 노출, 라이선스 위반,
복구 불가능한 변이, 사용자 범위 침해처럼 구체적 악영향이 입증된 부분만 통합하지 않으며 같은 출처의
안전한 지식·테스트·패턴은 계속 흡수한다.

## 4. 후보 처리 규칙

| 조건 | 처리 |
|---|---|
| 85점 이상 | 핵심 채택 후보. 실제 제품 경로 파일럿과 회귀 게이트를 의무 수행 |
| 75~84점 | 적극 파일럿. 동급 후보와 동일 과업 비교 후 채택 또는 역할 분리 |
| 60~74점 | 보조 후보. 특정 역할에서 상위 후보를 보완할 때 파일럿 |
| 60점 미만 | 즉시 삭제하지 않는다. 부족한 근거와 재평가 조건을 기록 |
| 카테고리 상위 3개 또는 유지보수되는 고별 저장소 | 점수 확정 전이라도 파일럿 목록에 포함 |

라이선스 비용이나 상용 조건은 제외 사유가 아니다. 사용할 수 있는 라이선스를 취득하거나 조건을 준수한다.
법적으로 사용할 수 없는 자산만 제품 배포 대상에서 제외하며, 그 경우 동일 품질의 합법적 파생 파이프라인을
구축한다.

## 5. 필수 파일럿 규격

각 기술 파일럿은 장식 데모가 아니라 다음 실제 표본 중 하나를 사용한다.

- 철 주괴·철판·철봉·나사·강화 철판을 포함한 생산 그래프
- 2×2 이상 토대, 제련기·제작기·조립기·분배기·병합기와 실제 컨베이어
- 파이프와 리프트가 벨트·기계 위아래를 교차하는 다층 공정
- 100대, 1,000대 설비의 팬·줌·선택·검증 성능 표본
- 실제 세이브 또는 라이선스가 확인된 블루프린트의 왕복 해석
- 동일 모델의 랜딩 장면, 편집기, 독립 SVG와 고해상도 PNG 비교

파일럿 결과에는 스크린샷, 성능 측정값, 접근성 결과, 콘솔·네트워크 오류, 번들 크기와 실패 사례를 남긴다.

[Ponytail 원 저장소](https://github.com/DietrichGebert/ponytail)는 2026-08-21 기준 약 10.17만 스타,
210커밋, MIT, Codex 플러그인 4.9.0이다. 공개한 12개 실제 기능 과업 벤치마크는 평균 54% LOC 감소를
보고하지만 Haiku 4.5 단일 계열과 한 FastAPI+React 저장소 중심이라는 한계가 있다. 프로젝트 적용 점수는
다음과 같다.

| 후보 | 점수 | 판정 | 적용 범위 |
|---|---:|---|---|
| `ponytail-review` | 89 | 핵심 채택 | 정상 정확성·보안·접근성 리뷰 이후 diff 축소 검토. 자동 수정 금지 |
| `ponytail-audit` | 87 | 핵심 채택 | G-30 전수 인벤토리의 중복·죽은 계층·불필요 의존성 감사 |
| 메인 `ponytail` 항상-on | 72 | 보조 파일럿 | 명시된 전체 제품 범위를 YAGNI로 축소할 위험 때문에 기본 활성화하지 않음 |

review와 audit은 보고만 하고 수정하지 않으며 정확성·보안·성능 검토를 대체하지 않는다. 메인 모드의
“명시적으로 요청한 기능은 줄이지 않는다” 경계는 유효하지만, 이 제품은 장기 범위 대부분이 복잡하고
필수이므로 최소 구현 우선 편향을 전역 기본값으로 두지 않는다.

R-01~R-12 연구가 안정되면 `skill-creator`로 저장소 전용 스킬을 만든다. 후보는 게임 데이터 외부 주장
검증, 탑뷰 자산 파이프라인, 공장 기하 검증, 도면 시각 QA다. 조사 전에 절차를 고정하지 않는다.

## 8. 계획 확정 게이트

다음 조건 전에는 전면 구현 계획을 완료로 표시하지 않는다.

1. R-01~R-12 문서가 모두 존재하고 필수 출처와 점수표가 채워짐
2. 각 카테고리 상위 후보와 고별·활성 프로젝트의 파일럿 여부가 판정됨
3. Anders 원본과 실제 세이브·블루프린트 코퍼스의 출처·버전·사용 조건이 확인됨
4. 전체 라우트·컴포넌트·도메인·데이터·자산이 유지/재작성/합병/삭제/신규로 분류됨
5. 요구사항별 구현 작업, 선행조건, 자동 검증, 시각 증거가 `ROADMAP`에 연결됨

이 게이트 이후에만 구현 순서를 확정한다. 이미 존재하는 미검증 구현은 후보로 남기고 정본으로 간주하지
않는다.
