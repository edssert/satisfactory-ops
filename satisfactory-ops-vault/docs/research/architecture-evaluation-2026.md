# 프론트엔드 및 배포 아키텍처 재평가 2026

## 1. 목적

기존 Astro 채택을 전제로 하지 않고 Satisfactory Ops의 현재 제품 요구만으로 전달 프레임워크를 다시
평가한다. 기존 코드 재작성 비용은 점수에서 제외한다. 결과가 달라질 경우 전면 마이그레이션을 허용한다.

평가일은 2026-08-21이다. 후보의 공식 저장소, 정적 배포 문서, 프리렌더 동작을 근거로 사용했다.

## 5. 비판적 판정

### 5.1 Astro의 실제 강점

가이드·도감·버전·참조 경로는 값과 한국어 콘텐츠를 빌드 시 HTML로 고정해야 한다. Astro는 이 요구를
별도 프리렌더 계층 없이 기본 동작으로 충족한다. 계산기·설계 스튜디오에는 Preact, 랜딩에는 GSAP,
실제 게임 메시 장면에는 Three.js를 경로 단위로 로드할 수 있다. 정적 GitHub Pages 하위 경로도 현재
배포 경계와 직접 맞는다.

### 5.2 기존 Astro 운영 방식의 결함

“상태를 소유하는 최소 단위만 아일랜드”라는 기존 규칙은 설계 스튜디오처럼 캔버스·선택·클립보드·Undo·
레시피·라우팅 상태가 강하게 결합된 화면을 작은 아일랜드로 쪼개도록 유도할 수 있다. 이 방식은 상태 계약과
이벤트 브리지를 늘려 제품 개발을 늦춘다.

따라서 경계를 컴포넌트 크기가 아니라 **사용자 작업 공간**으로 정의한다.

- 문서·도감 경로: Astro HTML 중심, 필요한 작은 상호작용만 아일랜드
- 계산기 경로: 하나의 완전한 Preact 애플리케이션 경계 허용
- 설계 스튜디오 경로: 캔버스·패널·명령·상태를 포함하는 하나의 완전한 Preact 애플리케이션 경계
- 지도·세이브 진단: 작업 상태 공유 범위에 따라 각각 하나의 앱 경계
- 랜딩: 정적 HTML을 기반으로 GSAP·Lenis·Three.js 장면을 점진 로드

### 5.3 SvelteKit과 React Router의 경쟁력

SvelteKit은 설계 스튜디오가 제품의 대부분을 차지하게 될 경우 가장 강한 대안이다. 컴파일 기반 UI와
정적 어댑터가 한 프레임워크 안에서 문서와 앱을 모두 처리한다. React Router는 복잡한 앱 상태와 라우팅이
제품 중심이 되고 React 생태계의 캔버스·테스트 도구를 직접 활용할 때 우위가 있다.

현재 요구에서는 두 후보 모두 문서 HTML·빌드타임 데이터·오프라인과 앱 UI를 충족한다. Astro보다 낮은
점수는 이전 코드 재사용 때문이 아니라, 이 제품이 여전히 정적 지식 경로와 고밀도 앱 경로를 동시에 크게
가지며 Astro가 두 전달 모드를 기본 경계로 제공하기 때문이다.

### 5.4 Next.js와 Vite 판정

Next.js 정적 export는 가능하지만 서버 기능, Route Handler, 내장 이미지 최적화 등 주요 강점이 정적
배포에서 제한된다. 백엔드 없는 로컬 앱이라는 현재 요구에서 프레임워크의 핵심 장점을 충분히 사용하지
못한다. Vite 단독은 설계 스튜디오에는 가장 자유롭지만 79개 이상의 HTML 경로, 콘텐츠 생성, 메타데이터,
무 JS 전달을 별도 시스템으로 다시 구성해야 한다.

## 6. 결정

1. Astro 7을 정적 전달 셸로 유지한다.
2. Preact 아일랜드의 크기는 “최소 컴포넌트”가 아니라 “독립 사용자 작업 공간”으로 정한다.
3. 설계 스튜디오와 계산기는 각 경로 안에서 완전한 클라이언트 애플리케이션으로 진화할 수 있다.
4. 프레임워크 도입을 제한하는 영구 규칙은 두지 않는다. 아래 재검토 조건이 발생하면 동일 가중치로 다시
   평가하고 SvelteKit 또는 React Router 마이그레이션 파일럿을 만든다.

## 7. 재검토 조건

- 설계 스튜디오·계산기·지도 사이에서 하나의 클라이언트 라우터와 상태 트리가 필수화되는 경우
- 정적 문서 경로가 제품 사용의 20% 미만으로 감소하는 경우
- Astro 아일랜드 간 통신 코드가 작업 공간 내부 상태 코드보다 커지는 경우
- 오프라인 업데이트, Web Worker, WASM, Three.js 청크 제어를 Astro/Vite 통합이 방해하는 경우
- Preact 생태계가 필요한 캔버스·접근성·테스트 요구를 충족하지 못하는 경우
