## 연구 문서 계약

주제별 문서는 하나만 유지한다. 문서는 검증 질문, 출처 URL과 접근일, 원문에서 확인한 사실, 앱 적용,
불확실성과 재검증 조건을 포함해야 한다. 검색 결과 요약, 세션 로그, 출처 채널별 노트는 근거로 남기지 않는다.
