# 기술 결정 등록부

현재 유효한 결정만 유지한다. 과거 초안과 Claude 조사 결과는 결정 근거로 사용하지 않는다. 결정이 바뀌면
해당 행을 수정하고 Git 이력으로 변경을 추적한다.

| ID | 결정 | 근거 | 재평가 조건 |
|---|---|---|---|
| D-001 | 별도 볼트 `satisfactory-ops-vault`에서 문서를 관리한다 | 앱 소스와 문서 UI 설정을 분리하면서 동일 저장소에서 버전 관리 | 저장소 분리 필요 발생 |
| D-002 | 속성은 Research의 `confidence`만 선택적으로 사용한다 | 파일명·H1·Git 이력이 나머지 메타데이터를 대체 | 자동화에 필요한 필드가 명확히 생김 |
| D-003 | Astro는 정적 셸, Preact는 라우트 단위 작업 공간으로 사용한다 | [[architecture-evaluation-2026]] | [[ENGINEERING]] 8절 조건 |
| D-004 | 계산기는 제품의 핵심 기능이다 | 사용자가 직접 요구한 제품 범위 | 없음 |
| D-005 | 공간 자동 배치는 제외하고 사용자가 최종 배치를 통제한다 | 사용자가 직접 요구한 편집 방식 | 사용자가 범위를 변경함 |
| D-006 | 사용자 데이터와 세이브는 브라우저 밖으로 전송하지 않는다 | 개인정보와 오프라인 작업 | 명시적 서버 기능 승인 |
| D-007 | 랜딩 복합 스크롤 서사는 GSAP, 입력 보간은 Lenis, Preact 상태 전환은 Motion으로 역할을 분리한다 | [[frontend-landing-technology-2026]] | 성능·접근성 회귀 또는 메이저 변경 |
| D-008 | 기존 Claude 연구와 크롤링 자료를 근거에서 제외하고 다시 조사한다 | 사용자의 신뢰 철회 | 재조사와 독립 검증 완료 |
