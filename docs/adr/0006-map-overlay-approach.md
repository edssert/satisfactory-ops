# ADR-0006: 실제 게임 맵 이미지 위에 캘리브레이션된 그리드를 오버레이한다

- **상태**: 채택
- **날짜**: 2026-08-19

## 맥락
입지 선정 화면은 "어디에 베이스를 지을지"를 판단하게 해야 한다. 처음에는 바이옴 배치를 손으로 그린 SVG 개략도로 만들었으나, 사용자가 실제 지도를 요구했다. 타당한 지적이다 — 개략도로는 지형과 거리감을 판단할 수 없다.

공식 위키에서 `Biome_Map.jpg`를 확보했다. 이 이미지는 이미 다음을 포함한다:
- 월드 그리드와 좌표 라벨 (X0Y0 ~ X6Y5)
- 바이옴 이름과 경계
- 4개 시작 지점 표시 (START 1~4)

## 결정
실제 바이옴 맵 이미지를 배경으로 쓰고, 그 위에 추천 부지 핀을 SVG로 오버레이한다.

핀 위치는 이미지 픽셀 좌표를 그리드에 맞춰 캘리브레이션해 산출한다. 1600×1600 원본 기준 측정값:

- 세로 그리드선: `x = 31 + 218.857 · i` (i = 0..7)
- 가로 그리드선: `y = 142 + 219.167 · j` (j = 0..6, j=0이 최상단 = Y5)

셀 (X, Y)의 중심:
```
cx = 31  + (X + 0.5) · 218.857
cy = 142 + (5 - Y + 0.5) · 219.167
```

좌표는 **비율(0~1)로 저장**해 이미지 표시 크기에 무관하게 만든다.

검증: 이 식으로 계산한 X2Y0 중심이 이미지의 "GRASS FIELDS (START 1)" 라벨 위치와 일치했다. 나머지 3개 시작 지점도 확인했다.

## 근거
- 이미지에 이미 그리드가 그려져 있으므로 별도 그리드를 그릴 필요가 없다. 핀만 얹으면 된다
- 비율 좌표는 반응형과 확대·축소에 자연스럽게 대응한다
- 캘리브레이션 값을 문서화해두면 나중에 다른 맵 이미지로 교체할 때 절차를 재현할 수 있다

## 결과
- 이미지가 교체되면 캘리브레이션을 다시 해야 한다. 측정 절차를 `docs/research/`에 남긴다
- 노드 단위의 정밀한 확인은 이 화면으로 불가능하다. SCIM 인터랙티브 맵으로 연결한다
- 게임 자산 의존이 생긴다 (ADR-0003의 리스크). 제거 요구 시 개략도로 후퇴한다

## 검토한 대안
- **손으로 그린 개략도**: 지형·거리 판단 불가. 실제로 만들어봤으나 사용자가 거부했다
- **인터랙티브 맵 자체 구현**: SCIM이 이미 압도적이다. ADR-0005에 따라 하지 않는다
- **핀 위치를 눈대중으로 배치**: 재현 불가능하고 이미지 교체 시 전부 다시 해야 한다
