# ADR-0003: 공개 저장소로 만들고 게임 자산은 출처를 명시해 번들한다

- **상태**: 채택
- **날짜**: 2026-08-19

## 맥락
앱은 Satisfactory의 월드 맵 이미지와 건물 아이콘을 사용한다. 이 자산은 Coffee Stain Studios의 것이며 공식 위키(satisfactory.wiki.gg)에서 가져왔다.

동시에 사용자는 GitHub Pages 배포를 원했고, 무료 플랜에서 Pages는 공개 저장소에서만 동작한다.

또한 배포된 페이지는 외부 호스트로의 요청 없이 동작해야 한다 (오프라인 요구, 프라이버시). 즉 이미지를 핫링크할 수 없고 번들해야 한다.

## 결정
- 저장소를 **public**으로 만들고 GitHub Pages로 배포한다
- 코드와 원본 저작물은 **MIT**
- `assets/` 하위 게임 이미지는 **MIT 적용 대상에서 명시적으로 제외**하고, LICENSE에 별도 고지를 둔다
- 이미지는 최적화(WebP 변환·축소)해 번들한다. 현재 총 648 KB
- 앱과 랜딩페이지에 출처와 "비공식 팬 프로젝트"임을 명시한다
- 권리자 요청 시 즉시 제거한다는 문구를 LICENSE에 넣는다

## 근거
- 팬 제작 도구가 게임 자산을 참조용으로 쓰는 것은 이 커뮤니티의 오랜 관행이다 (SCIM, satisfactorytools 등이 모두 그렇다)
- 비상업적이고, 게임을 대체하지 않으며, 게임 플레이를 보조한다
- 출처 명시와 제거 절차를 갖추는 것이 성실한 대응이다
- 이미지를 축소·최적화해 원본 재배포가 아닌 참조용 사용임을 분명히 한다

## 결과
- 저장소 내용이 공개된다. 개인 정보나 비밀을 커밋하지 않도록 주의해야 한다
- 사용자 데이터는 어차피 서버에 가지 않으므로 공개와 무관하다
- 게임사 요청 시 자산을 제거하면 앱 일부 기능(맵 화면)이 축소된다. 그 경우 개략도로 후퇴한다

## 검토한 대안
- **Private + Pages 없음**: 자산 문제는 없으나 사용자가 배포를 원했다
- **이미지 핫링크**: 오프라인 요구 위반, 위키 서버에 부하, 링크 깨짐 위험
- **직접 그린 개략도만 사용**: 이미 시도했으나 사용자가 실제 지도를 요구했고, 판단에 실제로 더 유용하다
