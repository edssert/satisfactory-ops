# ADR-0025: 도면은 검증된 단일 공장 도메인에서만 생성한다

- 상태: Accepted
- 날짜: 2026-08-21

## 맥락

기존 계산, 플래너, 흐름도, 도면 코드가 서로 다른 배치 모델을 사용했다. 포트 위치가 없을 때 전·후면
중앙을 추정했고, 실제 축척과 연결 가능성을 증명하지 않은 SVG도 완성 도면처럼 노출됐다.

## 결정

새 `src/domain/factory/`를 계산·편집·검증·렌더링의 단일 정본으로 둔다.

- 좌표 단위는 미터이며 게임 원본의 하드 클리어런스 박스를 보존한다.
- 포트는 위치, 방향, 매체, 출처, 신뢰도를 가진다.
- 검증된 포트가 없는 설비는 목록에서 볼 수 있어도 자동 도면 발행 대상이 아니다.
- 렌더러는 좌표를 새로 계산하지 않고 검증된 `FactoryPlan`만 투영한다.
- 충돌·지지·접속·용량·유량·전력 오류가 하나라도 있으면 발행을 차단한다.
- 최적화는 실행 가능한 후보 집합에만 적용한다.

## 결과

기존 `floorplan.ts`, `module-plan.ts`, `FactoryDrawing.tsx`, `ModuleSheet.astro`는 새 도메인의 정본이
아니다. 새 스튜디오가 대체한 뒤 삭제한다. 마이그레이션 중에도 해당 출력을 랜딩의 신뢰 증거로 쓰지 않는다.
