# ADR-0017: 한국어 표시명은 게임 공식 로케일 파일을 정본으로 한다

- **상태**: 채택
- **날짜**: 2026-08-19
- **관련 결정**: ADR-0004(한국어 우선·영문 병기), ADR-0008(게임 데이터 소스), ADR-0012(앱 데이터 계층)

## 맥락
CLAUDE.md는 게임 용어를 `한글(영문)`으로 병기하라고 정했고, 예시로 `강화 철판(Reinforced Iron Plate)`을 들었다.
그런데 게임이 배포하는 공식 한국어 로케일(`CommunityResources/Docs/ko.json`)을 실제로 파싱해보니 표시명이
**`보강된 철판`**이었다. 커뮤니티 통용 표기(`강화 철판`)와 게임 UI 표기가 다르다.

같은 종류의 불일치가 여럿 있다. 예: `Desc_SteelPlate_C`는 영문이 `Steel Beam`인데 클래스명은 `SteelPlate`다.
사람의 기억이나 커뮤니티 관행으로 이름을 적으면 게임 화면과 대조가 안 된다.

## 결정
**게임 `ko.json`의 표시명을 정본으로 한다.** `scripts/build-data.mjs --locale=ko`로 생성해
`src/data/ko/`에 두고, 앱 데이터 빌드가 클래스명으로 en/ko를 조인한다.

- 1차 표기: 게임 공식 한국어명 (`보강된 철판`)
- 병기: 영문 공식명 (`Reinforced Iron Plate`) — 위키·영문 공략·외부 계산기와 대조하기 위해
- 커뮤니티 통용어가 크게 다른 경우(`강화 철판`)는 **용어집(`glossary.json`)의 별칭**으로만 기록한다.
  본문 표기로 쓰지 않는다.
- 사람이 게임 아이템 이름을 타이핑하는 것을 금지한다. 화면의 이름은 전부 데이터에서 온다.

## 근거
1. **사용자는 게임 UI를 보면서 이 앱을 쓴다.** 앱이 `강화 철판`이라고 하는데 게임 제작 메뉴에는 `보강된 철판`이
   있으면, 앱이 틀린 것이다. 대조 가능성이 이 앱의 존재 이유다(ADR-0004의 병기 원칙과 같은 논리).
2. 공식 로케일은 **게임 개발사가 패치마다 갱신하는 유일한 한국어 소스**다. 번역이 바뀌면 재빌드로 따라간다.
3. 수기 번역 사전은 750개 아이템 × 패치마다 재검수다. 비현실적이고, 조용히 낡는다.

## 결과
- CLAUDE.md의 예시(`강화 철판`)는 이 ADR 이후 부정확하다. 문서 예시를 `보강된 철판(Reinforced Iron Plate)`으로 갱신한다.
- `src/data/ko/`가 저장소에 추가된다(약 2.1MB). 빌드 소스이며 배포 페이로드가 아니다.
- 게임 번역이 어색한 항목이 있어도 앱이 임의로 고치지 않는다. 필요하면 용어집에서 설명을 덧붙인다.

## 검토한 대안
- **커뮤니티 통용 표기 채택**: 검색·소통에는 유리하나 게임 화면과 대조가 깨진다. 출처도 불명확하다
- **양쪽 병기(`보강된 철판 / 강화 철판`)**: 표가 지저분해지고 어느 쪽이 정본인지 흐려진다. 용어집 별칭으로 해결한다
- **영문만 사용**: 한국어 우선 원칙(ADR-0004) 위반
