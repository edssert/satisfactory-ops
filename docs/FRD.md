## 0. 공통 요구

| ID | 요구 | 수준 |
|---|---|---|
| G-1 | 모든 게임 용어는 한글(영문) 병기로 표시한다 | MUST |
| G-2 | 모든 수치에는 출처와 신뢰도가 데이터에 기록되어 있다. `disputed`는 UI에서 시각적으로 구분한다 | MUST |
| G-3 | 자원·상태 구분에 색상만 쓰지 않는다. 텍스트 라벨을 병기한다 | MUST |

| G-5 | 라이트/다크 테마를 모두 지원하고 OS 설정을 따른다 | MUST |

## F1. 마일스톤 진행 체크리스트

### 목적
사용자가 현재 어디까지 왔는지 앱이 알고, 그에 맞춰 "지금 할 일"을 제시한다. **이 앱의 중심 기능이다.**

### 요구
| ID | 요구 | 수준 |
|---|---|---|
| F1-1 | T0~T9의 모든 마일스톤을 티어별로 표시한다 | MUST |
| F1-2 | 각 마일스톤에 해금 요구 부품과 수량을 표시한다 | MUST |
| F1-3 | 마일스톤을 완료로 체크할 수 있고, 체크 상태가 영속된다 | MUST |
| F1-4 | 체크 상태에 따라 **"현재 티어"를 자동 판정**하고 상단에 고정 표시한다 | MUST |
| F1-5 | 현재 티어에서 **다음에 할 일 3가지**를 우선순위와 함께 제시한다 | MUST |
| F1-6 | 각 마일스톤에 "이 시점 액션"과 "확장성 함정"을 표시한다 | MUST |
| F1-7 | 미래 티어의 내용을 미리 볼 수 있다 (스포일러 토글) | SHOULD |
| F1-8 | 완료율을 티어별/전체로 표시한다 | SHOULD |
| F1-9 | 마일스톤에서 관련 용어집 항목·단계도·계산기로 이동할 수 있다 | MUST |

### 예외·경계
- 체크 상태가 없는 최초 방문 → T0부터 시작하는 것으로 간주하고 온보딩 표시
- 사용자가 상위 티어를 체크했는데 하위가 비어 있음 → 경고하지 않는다 (건너뛰기 허용). 단 "현재 티어" 판정은 **체크된 것 중 최고 티어**를 쓴다

## F2. 입지 선정

### 목적
게임 시작 전 베이스 위치를 근거를 갖고 고르게 한다.

### 요구
| ID | 요구 | 수준 |
|---|---|---|
| F2-1 | 실제 게임 바이옴 맵 이미지를 표시한다 | MUST |
| F2-2 | 맵 위에 월드 그리드(X0Y0~X6Y5)를 정확히 정렬해 오버레이한다 | MUST |
| F2-3 | 추천 부지를 핀으로 표시하고, 클릭 시 상세(자원·물·지형·출처)를 보여준다 | MUST |
| F2-4 | 확대·축소·이동이 가능하다. 터치 제스처를 지원한다 | MUST |
| F2-5 | 4개 시작 지점을 구분해 표시한다 | MUST |
| F2-6 | 그리드 오버레이·핀·라벨을 각각 켜고 끌 수 있다 | SHOULD |
| F2-7 | 시작 지점 4곳의 비교표를 제공한다 (지형/자원/물/바이오매스/난이도) | MUST |
| F2-8 | 공략별 1위와 **이견이 갈리는 지점**을 명시한다 | MUST |
| F2-9 | 노드 단위 상세 확인은 외부 인터랙티브 맵으로 연결한다 | MUST |
| F2-10 | 1.2 자원 랜덤화 사용 시 이 화면의 조언이 무효임을 경고한다 | MUST |

### 예외·경계
- 그리드 정렬 기준: 1600×1600 원본에서 세로선 `x = 31 + 218.857i`, 가로선 `y = 142 + 219.167j`. 좌표는 비율로 저장해 이미지 크기 변경에 무관하게 한다
- 맵 이미지 로딩 실패 → 그리드와 핀만으로 된 개략도로 후퇴

## F3. 공장 성장 단계도

### 목적
T0의 단선 라인이 기차 물류망까지 어떻게 뻗어나가는지, 각 단계의 배치·배관·배선을 보여준다.

### 요구
| ID | 요구 | 수준 |
|---|---|---|
| F3-1 | Stage 0~6의 단계별 다이어그램을 제공한다 | MUST |
| F3-2 | 각 단계에 배치·배관·배선 항목을 분리해 설명한다 | MUST |
| F3-3 | 각 단계에 "다음 단계로 넘어가는 조건"을 명시한다 | MUST |
| F3-4 | 다이어그램은 라이트/다크 테마에 모두 대응한다 | MUST |
| F3-5 | 현재 티어에 해당하는 단계를 강조 표시한다 | SHOULD |
| F3-6 | 다이어그램은 가로 스크롤 컨테이너 안에서만 넘친다 (본문 가로 스크롤 금지) | MUST |
| F3-7 | 각 다이어그램에 대체 텍스트를 제공한다 | MUST |

## F4. 용어집 (학습 레이어)

### 목적
공정 용어를 **처음 필요해지는 시점에** 설명한다. 이 앱의 차별점.

### 요구
| ID | 요구 | 수준 |
|---|---|---|
| F4-1 | 각 용어에 요약·왜·방법·함정을 구조화해 제공한다 | MUST |
| F4-2 | 각 용어에 "처음 필요해지는 티어"를 표시한다 | MUST |
| F4-3 | 현재 티어에 해당하는 용어를 우선 노출한다 | SHOULD |
| F4-4 | 용어 간 상호 참조 링크를 제공한다 | MUST |
| F4-5 | 본문 어디서든 용어를 만나면 인라인으로 정의를 볼 수 있다 | SHOULD |
| F4-6 | 검색이 가능하다 (한글·영문 모두) | SHOULD |

## F5. 생산 라인 계산기

### 목적
목표 생산량에서 필요 기계 수와 원광 소모를 역산한다.

### 요구
| ID | 요구 | 수준 |
|---|---|---|
| F5-1 | 품목과 목표 개/분을 입력하면 전체 하위 체인을 역산한다 | MUST |
| F5-2 | 중간재별 필요 생산량, 기계 종류, 기계 수(소수점)를 표시한다 | MUST |
| F5-3 | 올림 배치 시 언더클럭 비율을 함께 제시한다 | MUST |
| F5-4 | 원광 총 소모량과 순수 노드 환산, 필요 채굴기 수를 표시한다 | MUST |
| F5-5 | 사용자가 확보한 대체 레시피를 반영해 계산한다 (F7 연동) | MUST |
| F5-6 | 산출 벨트에 필요한 컨베이어 등급을 제시한다 | SHOULD |
| F5-7 | 순환 레시피(Recycled Plastic ↔ Rubber)에서 무한 재귀에 빠지지 않는다 | MUST |
| F5-8 | 계산 결과를 저장·복원할 수 있다 | MAY |

### 예외·경계
- 순환 감지 시: 깊이 제한 또는 방문 집합으로 중단하고 사용자에게 순환 구간을 알린다 (ADR-0013)
- 목표값이 0 이하 → 입력 오류 안내
- 해당 품목의 레시피가 데이터에 없음 → 계산 불가를 명시하고 외부 도구로 연결

## F9. 공장 상태 관리

> 사용자 결정으로 포함. 입력 부담이 최대 리스크이므로 **F10 세이브 임포트로 자동 채우는 것을 1차 경로**로 삼는다.

| ID | 요구 | 수준 |
|---|---|---|
| F9-1 | 생산 라인을 등록할 수 있다 (품목, 기계 종류·수, 클럭) | MUST |
| F9-2 | 등록된 라인의 실효 생산량을 계산해 표시한다 | MUST |
| F9-3 | 라인 간 투입·산출을 합산해 **부족·잉여를 진단**한다 | MUST |
| F9-4 | 총 전력 소비 추정치를 표시한다 | SHOULD |
| F9-5 | 수동 입력은 최소화한다. 한 라인 등록에 3단계를 넘지 않는다 | MUST |
| F9-6 | 세이브 임포트로 자동 채워진 항목과 수동 입력 항목을 구분 표시한다 | MUST |

## F10. 세이브 파일 임포트

> 범위는 ADR-0014의 결론을 따른다. 아래는 목표 범위이며, 리서치 결과에 따라 축소될 수 있다.

| ID | 요구 | 수준 |
|---|---|---|
| F10-1 | 로컬 .sav 파일을 선택해 읽는다. 서버로 전송하지 않는다 | MUST |
| F10-2 | 파싱은 Web Worker에서 수행해 UI를 막지 않는다 | MUST |
| F10-3 | 진행률을 표시하고 취소할 수 있다 | MUST |
| F10-4 | 해금된 마일스톤·스키매틱을 추출해 F1에 반영한다 | MUST |
| F10-5 | 확보한 대체 레시피를 추출해 F7에 반영한다 | MUST |
| F10-6 | 건설된 건물 종류·수량을 추출해 F9에 반영한다 | SHOULD |
| F10-7 | 지원하지 않는 세이브 버전은 **명확히 거부**하고 수동 입력을 안내한다 | MUST |
| F10-8 | 파싱 실패 시 기존 진척 데이터를 훼손하지 않는다 | MUST |
| F10-9 | 임포트 전 현재 진척을 백업하고 되돌릴 수 있다 | MUST |
| F10-10 | 게임 모드 설정(자원 랜덤화 여부)을 읽어 F2에 경고를 연동한다 | SHOULD |

### 예외·경계
- 파일 크기가 임계값 초과 → 경고 후 진행 여부를 사용자에게 확인
- 압축 해제 실패·구조 불일치 → 부분 성공 금지. 전부 롤백하고 원인을 안내
