# Satisfactory 버전 연혁 — 1.0 정식 출시(2024-09-10) ~ 현재(1.2)

> 조사일 2026-08-20
> **1차 출처**: 공식 위키 `satisfactory.wiki.gg` 의 Patch 문서 **원문**(`?action=raw` 로 직접 내려받아 읽음, 요약본 아님). 각 Patch 문서는 상단 템플릿에 Coffee Stain 공식 Steam 뉴스 URL·빌드번호·날짜를 담고 있으며, 이 문서의 날짜와 빌드번호는 전부 거기서 가져왔다.
> **대조 데이터**: 이 저장소의 `src/data/app/*`, `src/data/schematics.json` (현재 설치본 `Docs.json` 파생 — `steamBuildId 24656030`, 게임 갱신 2026-08-18, 추출 2026-08-19)
> **범위**: 진행·설계 판단에 영향을 주는 변경만. **버그 수정·성능 개선·번역 수정·비주얼·컨트롤러·사진 모드·전용 서버는 담지 않았다.**

## 이 문서를 왜 만들었고 어떻게 쓰나

이 앱은 커뮤니티 공략을 근거로 쓴다. 공략마다 작성 시점이 다르므로 "1.0 이후인가"만으로는 부족하다. 이 표는 **공략을 읽을 때 어느 대목만 의심하면 되는지** 알려주는 필터다.

이번 조사의 가장 중요한 결론부터 적는다:

> **1.1과 1.2는 레시피 비율·전력·처리량·티어 구성·마일스톤 비용·우주 엘리베이터 페이즈 요구량을 하나도 바꾸지 않았다.**
> 두 업데이트가 추가한 것은 전부 **새 건물·새 물류 부품·새 시스템**이다. 따라서 **1.0 시점(2024-09-10 이후) 공략의 수치는 지금도 그대로 유효하다.**
> 반대로 **1.0 이전(얼리액세스 Update 8 이하) 공략의 수치는 상당수가 낡았다.** 의심의 경계선은 1.0이지 1.1·1.2가 아니다.

`src/data/curated/version-history.json` 의 `$purpose`("이 표는 자료를 버리는 필터가 아니다")와 같은 취지다. 1.1·1.2 공략과 1.0 공략은 **수치 면에서 서로 다르지 않다** — 다른 것은 "쓸 수 있는 건물이 몇 개인가"와 "조작 절차"뿐이다.

#### (2) 새 건물·시스템

- **차원 창고(Dimensional Depot)** — MAM 외계 기술 연구. 자원을 업로드해 두면 위치와 무관하게 건설·제작에 바로 쓸 수 있다. **중반 이후 건설 물류를 통째로 바꾼 기능**이다. 상세는 §4.2.
- **생산 증폭기(Production Amplifier)** — 소머슬룹을 생산 건물에 넣어 산출을 증폭. 추가 자원 공급 없이 산출이 늘고 대신 전력이 크게 늘어난다.
- **외계 전력 증강기(Alien Power Augmenter)** — 소머슬룹으로 전력망 발전량을 증폭. 양자 인코더로 만든 외계 동력 매트릭스로 더 키울 수 있다.
- **변환기(Converter)** — S.A.M. 을 써서 원자재를 다른 원자재로 변환(석회석→철, 구리→카테리움 등). **"쓸모없는 노드"라는 개념 자체가 흔들린다.**
- **양자 인코더(Quantum Encoder)** — 최종 티어 생산 건물. 여기광 물질을 소비하고 암흑 물질 잔여물을 부산물로 낸다.
- **포털(Portal)** — 특이점 세포 + 막대한 전력으로 즉시 이동.
- **픽소니움(Ficsonium)** — 플루토늄 폐기물을 소비하고 **자체 폐기물을 만들지 않는** 핵연료. 핵폐기물 영구 처리 경로가 생겼다.
- **컨베이어 벨트/리프트 Mk.6** — **1200/분** (Mk.5 780/분 → 상한 상승). 순수 노드 + 오버클럭 채굴기 Mk.3 의 산출을 벨트 하나로 감당할 수 있게 됐다.
- **청사진 설계소 Mk.2(5×5 = 40 m³, T6) · Mk.3(6×6 = 48 m³, T9)** — Mk.1 은 4×4(32 m³)로 유지. Mk.1 은 Update 7부터 티어 4에 있었다.
- **HUB 최종판**, 파이오니어 커스터마이징, AWESOME 상점 신규 팩(창문·펜스·배리어·페인트 마감).

- 확장 단계는 **200% / 300% / 400% / 500%** 네 단계다. 게임 한글 표기가 `창고 확장 (200%)` 형식 그대로다. 실제 효과는 아이템 종류별 **스택 수 상한**(1 → 2 → 3 → 4 → 5스택)이고, 슬롯 방식이 아니라 **아이템별 쿼터** 방식이라 품목끼리 서로 자리를 뺏지 않는다.

- 업로더 자체는 **입력 컨베이어가 1개뿐이고 내부 버퍼가 1스택**이라, 업로더 하나로 여러 품목을 올리는 설계는 부적절하다.

## 5. 확인 못 함

지어내지 않고 그대로 남긴다.

1. **우주 엘리베이터 페이즈 4의 1.0 이전 비용과 이후 비용.** 패치노트는 "인하했다"고만 적고 수치를 밝히지 않았다([Space Elevator History](https://satisfactory.wiki.gg/wiki/Space_Elevator) 도 동일). 현재 페이즈별 요구량은 위키가 템플릿(`Template:Project Assembly phases`)으로 렌더링해 문서 원문에서 바로 읽히지 않고, 저장소 데이터에도 없다. **다만 1.1·1.2에서 페이즈 요구량이 바뀐 기록은 없다** — Space Elevator 문서 History 에 1.0 이후 항목이 하나도 없다.
2. **1.0의 "티어 3~8 마일스톤 비용 소폭 조정"의 구체 내역.** 패치노트에 수치가 없다. 현재값은 데이터로 알 수 있지만 **이전값을 확인할 근거가 없다.**
3. **1.0의 "저성능 대체 레시피 다수 조정"이 어느 레시피인지.** 패치노트가 레시피명을 밝히지 않았다.
4. **1.2.4.0의 빔 건설비 수정 — 이전값과 이후값.** "의도보다 높았다"고만 적혀 있다.
5. **월드의 머서 구체 총 298개.** 위키 서술이며 1.0 기준이라고 적혀 있다. 이 저장소의 `resource-nodes.json` 은 자원 노드만 담고 수집품(머서 구체·소머슬룹·하드드라이브)은 담지 않아 **대조 불가**.
6. **현재 설치본(`steamBuildId 24656030`, 2026-08-18)이 정확히 어느 게임 패치인지.** 위키에 문서가 있는 최신 패치는 **1.2.4.0(2026-08-11, 게임 빌드 502094)** 이고 그 이후 패치 문서는 없다. Steam 빌드 ID 와 게임 빌드 번호는 체계가 달라 직접 대응시킬 수 없다. 설치본이 1주 뒤(2026-08-18)에 갱신된 것은 **패치노트 없는 데포 갱신**이었을 가능성이 크지만 **확인하지 못했다.**
7. **1.2.0.0의 "패치노트 미기재" 변경들**(유체 화물 용량 증가, 트럭 정류장 일괄 적재, 자원 매장지 폭파 가능) — 출처가 **공식 패치노트가 아니라 위키 편집자의 확인**이다. 위키는 이를 명시적으로 "Undocumented change"로 표기하고 일부는 개발사 라이브스트림 영상을 각주로 단다. **`confidence: consensus` 로 다루고, 앱의 핵심 수치로 쓰기 전에 게임 안에서 직접 재확인해야 한다.**
8. **콘솔판(PS5 / Xbox Series S|X) 출시일.** 1.1·1.2 패치노트가 콘솔 출시를 반복해 언급하지만 이 조사는 PC 진행·설계 변경만 다뤘으므로 확인하지 않았다.

## 부록 — 조사 방법

- 위키 API `allpages` 로 `Patch 1.` 접두 문서 **46건 전부**를 열거한 뒤, `index.php?title=<문서>&action=raw` 로 **위키텍스트 원문**을 내려받아 읽었다. 요약을 거치지 않았으므로 수치 손실이 없다. (wiki.gg 는 요청 빈도 제한이 있으므로 커스텀 User-Agent + 요청 간 지연이 필요했다.)
- 각 Patch 문서 상단의 `{{patch}}` 템플릿에서 `date` · `build` · `steam` 값을 뽑아 날짜와 공식 URL 을 확정했다. **날짜를 추측한 곳은 없다.**
- 1.1·1.2에 수치 변경이 없다는 결론은 두 방향으로 교차 확인했다.
  1. 1.1·1.2 계열 패치노트 원문 **24건 전부**를 읽고 밸런스 항목을 찾았다 → 없음
  2. 위키 검색 API 로 `insource:"Patch 1.1.0.0"` · `insource:"Patch 1.2.0.0"` · `insource:"Patch 1.2.2.2"` 를 조회해 **해당 패치를 History 에 기록한 문서 전부**(각 54 / 41 / 15건)를 열거하고, 그중 진행·설계 관련 문서(자원 노드, 화물차, 화물 플랫폼, 트럭, 트럭 정류장, 채굴기, 컨베이어 벨트/리프트, 드론, 파이프라인 접합부, 전력선, 청사진 설계소, 인벤토리, 나사 등)의 History 절을 직접 읽었다 → 레시피·티어·페이즈 변경 없음. 대신 **1.2의 미기재 변경 3건을 새로 발견**
- 한글 표기는 전부 이 저장소의 게임 로케일 데이터(`src/data/ko/*`, `src/data/app/*` 의 `ko` 필드)에서 가져왔다. 커뮤니티 통용어가 아니라 **게임 공식 표기**다 (ADR-0017).
- WebSearch 는 **1회만** 썼다(1.2 출시일 초기 확인). 나머지는 전부 위키 원문·API 직접 조회다. 배정된 검색 예산 200회 중 1회 사용.
