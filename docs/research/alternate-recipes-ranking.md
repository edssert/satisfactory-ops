# 대체 제작법 우선순위 — 출처 셋과 자체 계산

조사일 2026-08-20. 게임 1.2 (Steam 빌드 24656030).

## 왜 자체 계산까지 했는가

처음에는 커뮤니티 순위 하나를 옮겨 적었다. 그게 규칙 위반이었다 —
`CLAUDE.md` 는 단일 출처 주장을 `disputed` 로 표시하고 앱 핵심 데이터로 쓰지 말라고 한다.

출처를 더 찾다가 두 가지가 드러났다.

1. **웹 검색 상위의 "티어 리스트" 사이트들은 독립 출처가 아니다.** 점수가 소수점까지 원문과
   같다(86.1 / 83.0 / 80.4 …). 한 사람의 분석을 SEO 사이트들이 옮긴 것이다.
2. **진짜 독립 출처를 찾으니 결과가 크게 달랐다.** 104건 중 두 등급 이상 벌어진 것이 46건이다.

그래서 **1.2 데이터로 직접 계산**했다. 두 외부 출처 모두 1.2 기준이 아니기 때문이기도 하다.

## 출처 1 — 선형계획 모형 (u/wrigh516)

- [Alternate Recipe Ranking 1.0 - Optimizing for Time/Effort](https://www.reddit.com/comments/1fekus9/), 2024-09-11, **게임 1.0**
- 게임 파일 데이터로 Pyomo + glpk 선형계획 모형을 돌려, 한 레시피를 강제했을 때 전체 생산망의
  전력·아이템 이동량·기계 수·자원 소모가 얼마나 바뀌는지로 점수를 매긴다.
- 가중치: 아이템 이동 0.4 · 기계(입출력 가짓수로 스케일) 30 · 자원(맵 가용량의 역수로 스케일) 1.0
- **시간·수고 최소화** 기준이다. 같은 저자가 자원 효율 기준 판도 따로 냈다.
- 같은 저자의 Update 4(2021) · Update 7(2023) 판이 있으나 **같은 사람이라 독립 출처가 아니다.**

## 출처 3 — 이 사이트의 자체 계산 (`scripts/rank-alternates.mjs`)

**끝점**: 우주 엘리베이터 페이즈 1~5 를 전부 납품하는 데 드는 총량.
초반만 보고 고른 제작법이 후반에 발목을 잡는 일이 흔하므로 끝까지 본다.

| 페이즈 | 요구 |
|---|---|
| 1 | 지능형 도금판 50 |
| 2 | 지능형 도금판 1,000 · 다목적 골조 1,000 · 자동 배선 100 |
| 3 | 다목적 골조 2,500 · 모듈식 엔진 500 · 적응형 제어 장치 100 |
| 4 | 조립 감독 시스템 500 · 자기장 발생기 500 · 열추진 로켓 250 · 핵 파스타 100 |
| 5 | 핵 파스타 1,000 · 생화학 조각기 1,000 · AI 확장 서버 256 · 탄도 워프 드라이브 200 |

출처: [공식 위키 Space Elevator](https://satisfactory.wiki.gg/wiki/Space_Elevator) (1× 배수).
**게임 배포 데이터에는 페이즈 요구량이 없다** — 에셋에만 있고 `Docs.json` 에 나오지 않는다.

**희소도 가중**: 원자재를 실제 맵의 노드 수로 가중한다. 순도별 개수가 데이터에 있으므로
(불순 ×0.5 · 보통 ×1 · 순수 ×2) 맵 전체 가용량을 추정할 수 있다. 가장 흔한 자원을 1 로 두고
귀할수록 큰 값을 준다.

| 자원 | 희소도 배수 | 페이즈 1~5 총 소요 |
|---|---|---|
| 철 광석 | ×1.00 | 1,588,351 |
| 석회석 | ×1.33 | 376,860 |
| 물 | ×1.61 | 405,375 |
| 석탄 | ×2.18 | 1,026,216 |
| 구리 광석 | ×2.50 | 2,156,455 |
| 원유 | ×2.84 | 676,019 |
| 석영 원석 | ×6.82 | 264,713 |
| S.A.M. | ×9.03 | 293,387 |

**점수** = 자원 절감 %×3 + 기계 절감 %×2 + 전력 절감 %×1.
자원을 가장 무겁게 두는 이유: 맵의 노드는 유한하고 늘릴 수 없다. 기계와 전력은 자원만 있으면 늘린다.
**이 가중치는 판단이다.** 바꾸면 순위도 바뀐다.

**등급**은 점수 분포의 분위수로 자른다(상위 5% = S, 20% = A, 45% = B, 70% = C, 90% = D).
임의의 절대값 경계를 쓰지 않는다.

### 한계

- 대체 제작법을 **하나씩만** 끼워 본다. 여러 개를 함께 썼을 때의 상호작용은 재지 않는다.
  출처 1은 이걸 한다 — 그 점에서 출처 1이 더 정교하다.
- 부산물을 다른 공정에 되먹이는 최적화를 하지 않는다.
- 기본 제작법이 없는 6건(목탄·유기 석탄·압축 석탄·자동화된 채굴기·폴리머 수지·중유 잔여물)은
  비교 대상이 없어 제외했다.
- 계산 중 부산물을 생산 경로로 잘못 잡아 없는 순환이 생기는 버그가 있었다
  (합성 동력 조각이 암흑 물질 잔여물을 부산물로 내는데 그것을 "잔여물 만드는 법"으로 집음).
  **주산물만** 생산 경로로 보도록 고쳤다.

### 자체 계산에서 특히 높게 나온 것 (1.2 기준)

| 제작법 | 점수 | 자원 | 기계 |
|---|---|---|---|
| 단련된 구리 주괴 | 44.4 | −15.97% | −1.28% |
| 구리 합금 주괴 | 41.0 | −8.20% | −8.46% |
| 포장된 고중량 골조 | 37.7 | −3.36% | −12.24% |
| 강철 나사 | 24.9 | −0.04% | −11.48% |

구리 계열이 상위를 차지하는 이유는 희소도 가중 때문이다 — 페이즈 1~5 전량에서
**구리 광석 소요가 철보다 많은데(2,156,455 vs 1,588,351) 맵의 구리 노드는 더 적다.**
구리를 아끼는 제작법이 그만큼 크게 평가된다. 이건 다른 두 출처가 잡아내지 못한 부분이다.

## 결론 — 앱에서 어떻게 쓰는가

1. **세 등급을 나란히 보여준다.** 하나를 정답으로 두지 않는다.
2. **세 곳이 모두 높게 본 6건**을 "가장 안전한 선택"으로 표시한다.
3. 35건은 "엇갈림"으로 표시하고 판단을 넘긴다.
4. 자체 계산의 가중치와 한계를 화면에 밝힌다. 감추면 남의 순위를 옮겨 적은 것과 다를 바 없다.
