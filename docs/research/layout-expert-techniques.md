## 1. 분배 시스템 — 언제 무엇을 쓰는가

조사로 확인된 성립 조건. FRD F13-J의 근거다.

| 시스템 | 성립 조건 | 실패 조건 |
|---|---|---|
| 매니폴드 | 총 소요 ≤ 공급 벨트 1줄 용량. 확장 예정 라인 | 총 소요 > 벨트 1줄이면 **끝단 기계가 영구히 굶는다** |
| 인젝티드 매니폴드 | 총 소요가 벨트 1줄을 넘을 때, 중간에 보조 벨트 병합 | 병합 지점 앞 **스마트 분배기(Overflow) 없으면 아이템이 샌다** |
| 로드 밸런서 | 즉시 100%가 필요한 곳 — 기차역·저장소 배열·싱크 | 확장할 때마다 재설계. 공간·자재 비용 큼 |
| 오버플로 분배 | 잉여를 싱크·저장소로 흘려 라인 정지 방지 | Overflow 출력은 **항상 2개를 버퍼로 붙잡는다** |
| 우선 병합기 | 한 입력을 우선 처리 (재활용 루프 등) | 티어 3 해금 |

**핵심 판정**: "매니폴드가 기본"은 맞지만 **무조건은 아니다.** 총 소요량과 벨트 1줄 용량을 비교하는
산수가 먼저다. 이 비교를 건너뛰고 매니폴드를 그리면 끝단 기계가 도는 일이 없다.

## 2. 배치·건축 기법 (숙련자 관행)

| 기법 | 내용 | 도면 생성에 주는 함의 |
|---|---|---|
| **넛지(Nudge)** | 미세 이동으로 파운데이션 격자에서 벗어난 정렬이 가능 | 격자 정합이 **절대 제약은 아니다.** 다만 도면은 재현 가능해야 하므로 기본은 격자 정합, 넛지는 예외로만 |
| **파운데이션 두께 선택** | 두꺼운 파운데이션(2m/4m)은 지형 정리에 유리하나 자재가 늘고 광석을 끌어올리기 어려워짐 | 층 구조 설계 시 두께가 변수. 4m는 층 구멍을 뚫어 리프트를 통과시키는 표준 수법 |
| **채굴기 관통** | 채굴기는 파운데이션 1m를 관통해 채굴 가능. 트릭으로 5m까지 | 채굴기 위에 바닥을 깔아도 된다 — 노드 위 공간을 낭비하지 않아도 됨 |
| **기둥 걸침** | 블루프린트 경계에 기둥은 부분적으로 걸쳐도 저장됨 | 경계 검사에서 기둥은 예외 처리 |
| **디자이너 철거 환급** | 블루프린트 저장 후 디자이너를 철거해도 자재 100% 환급 | 디자이너 건설비는 일회성으로 취급 가능 |
| **하위→상위 중첩** | Mk.1에서 만든 블루프린트를 Mk.2 디자이너 안에 넣을 수 있다 (역방향 불가) | 모듈을 작게 만들어 두면 나중에 더 큰 모듈로 합칠 수 있다 — **초반 32m 정렬의 근거** |

## 3. 1.1 / 1.2에서 바뀐 설계 전제

| 변경 | 내용 | 설계 영향 |
|---|---|---|
| **유체 트럭 정거장** (1.2) | 유체를 차량으로 운송 | **파이프 양정 제약을 우회하는 새 선택지.** 장거리 유체를 파이프로 끌지 않아도 된다 |
| **차량 경로 재작업** (1.2) | 수동 녹화 없이 경로 배치 가능 | 트럭 물류의 실용성이 올라감 → F13-H의 비교 대상에 트럭을 진지하게 넣어야 함 |
| **파이프라인 T자 분기** (1.2, 티어 3) | 배관 분기 전용 부품 | 배관 층 설계가 단순해짐 |
| **데이지 체인 전력** (카테리움 연구) | 건물 간 직접 전력 연결(한 건물에 전력 연결 2개) | 전주 배치가 줄어듦. 전력 배선 도면이 단순해짐 |

## 4. 이 조사가 도면 생성기에 요구하는 것

1. **매니폴드를 기본값으로 박아넣지 말 것.** 벨트 용량과 총 소요를 비교하는 판정이 먼저다 (F13-52)
2. **모듈 간격을 16m 이내로** 두면 오토커넥트가 붙는다 — 도면에 이 간격을 명시할 것
3. **32m(Mk.1) 배수 정렬**은 초반에도 지켜야 나중에 모듈로 승격된다 (F13-19)
4. **유체 장거리는 파이프가 유일한 답이 아니다** — 1.2 유체 트럭을 비교 대상에 포함 (F13-H)
5. **전력 배선은 데이지 체인 해금 여부로 달라진다** — 해금 상태를 반영 (F13-24와 같은 원칙)
6. 소머슬룹·클럭은 대수를 바꾸므로 **배치 전에 확정**되어야 한다 (F13-G)

## 6. 도면을 어떻게 그리는가 (2026-08-19 추가 조사)

처음 만든 도면이 "조각들을 세로로 쌓은 것"이 된 원인은 **표현 관행을 조사하지 않은 것**이었다.
도구 목록과 게임 치수는 조사했지만, 배치도를 어떻게 그리는지는 안 봤다.

| 관행 | 내용 | 우리 도면에 적용 |
|---|---|---|
| **산키 다이어그램** | 흐름량에 **선 굵기를 비례**시킨다. 생산 설비를 공정 순서대로 잇고 연결선 굵기가 물류 강도를 나타낸다 | 벨트 선 굵기 ∝ 분당 유량. 굵은 선이 곧 병목 후보다 |
| **스파게티 다이어그램** | **축척에 맞춘 평면도**를 먼저 깔고, 그 위에 실제 이동 경로를 선으로 그린다. 선이 꼬이는 곳이 낭비다 | 파운데이션 격자가 축척 평면도. 경로를 실제로 그려야 한다 — 이것을 빠뜨렸다 |
| **타입 있는 입출력 포트** (neXus) | 건물마다 입력·출력 포트를 명시하고 거기에만 연결한다 | 기계 사각형에 입력변·출력변을 표시하고 연결선을 그 지점에 붙인다 |
| **직각(L) 라우팅** (neXus) | 전선·벨트를 직각으로 꺾어 정렬한다 | 연결선을 직각 폴리라인으로. 대각선 금지 |
| **교차 병합** (neXus) | 컨베이어 교차를 자동 병합 처리 | 채널을 분리해 교차 자체를 줄인다 (구간 색칠) |
| **병목 심각도 표시** (neXus) | 병목을 등급으로 구분해 표시 | 벨트 상한을 넘는 구간을 강조 + 어느 품목이 원인인지 명시 |

### 층 간격 — 조사 결과가 갈린다

- neXus 도구는 **4m 수직 간격**을 쓴다
- 우리는 리프트 최소 길이 7m에서 **8m 층고**를 도출했다

둘 다 근거가 있다. 4m는 파운데이션 두께 배수로 정렬이 쉽고, 8m는 리프트가 성립하는 최소값이다.
**층간 물류를 리프트로 하면 7m 이상이 필요하고, 층 구멍으로 벨트를 직접 통과시키면 4m로도 된다.**
→ P3에서 층고를 옵션으로 두고 둘 다 지원하되, 리프트를 쓸 때는 7m 미만을 거부해야 한다.
