# 세이브 연결 그래프에서 설비 포트 좌표 복원

## 문제

게임의 `Docs/*.json`은 설비 크기는 제공하지만 포트 좌표를 제공하지 않는다. 기존 코드는 설비 전·후면
중앙을 포트로 추정했고, 그 추정을 실제 도면처럼 그렸다. 포트가 맞지 않으면 벨트가 설비에 닿아 보여도
게임에서 지을 수 없으므로 이 방식은 폐기한다.

## 관측 방법

1. 브라우저와 같은 파서로 `.sav`를 읽는다. 외부 전송은 없다.
2. 설비의 고체·유체·전력 연결 컴포넌트에서 연결된 컨베이어·파이프·전력선을 찾는다.
3. 스플라인 끝점 또는 전력선 양끝 변환으로 월드 좌표를 복구한다.
4. 설비 변환의 역행렬로 끝점을 로컬 좌표로 바꾼다.
5. 현재 게임의 충돌 상자 밖에 있는 관측을 폐기하고, 반경 0.05m의 최대 합의 군집을 찾는다.
6. 현재 로컬 세이브와 다른 제작자의 공개 세이브·블루프린트에서 일치한 경우에만 `verified`로 승격한다.

## 결과

현재 Satisfactory 1.2 로컬 세이브에서 고체·전력 연결 286건을 얻었다. 별도로 공개 세이브에서 18,037건,
서로 다른 제작자의 공개 블루프린트 6개에서 264건을 추출했다. 제작기·조립기·제련기·정유소의 고체,
유체, 전력 포트가 여러 출처에서 일치했다. 개인 세이브의 경로와 액터 식별자는 저장하지 않았다.
정규화 결과는 `src/data/curated/machine-ports.json`, 공개 코퍼스와 파일 해시는
`docs/research/public-save-blueprint-corpus.md`에 있다.

데이터가 없다는 이유로 중앙 포트를 만들지 않는다. 일부 포트만 관측한 설비도 완전한 도면 대상으로
승격하지 않는다.
