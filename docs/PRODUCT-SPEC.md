# 제품 통합 명세와 추적표

이 문서는 사용자 대화에서 확정된 요구를 구현·테스트·시각 검증까지 연결하는 **단일 추적 정본**이다.
제품의 이유는 [[PRD]], 기능 상세는 [[FRD]], 기술 제약은 [[TRD]], 구조는 [[ARCHITECTURE]]가 담당한다.

## 1. 제품 정의

Satisfactory의 실제 게임 데이터와 검증된 커뮤니티 지식을 사용해 다음 행동을 안내하고, 사용자가 직접
시공 가능한 공장을 설계하며, 실제 축척의 고품질 도면으로 내보내는 한국어 로컬 우선 웹앱이다.

계산 결과만 내는 도구가 아니다. **계획 → 직접 배치 → 연결 → 생산 설정 → 검증 → 시공 도면**을 한 모델로
이어야 한다. 랜딩에서 보여 주는 도면도 같은 모델을 통과한 실제 결과여야 하며, 장식용 가짜 도면은 금지한다.

## 2. 상태와 우선순위

| 표기 | 의미 |
|---|---|
| `완료` | 코드·테스트·실화면 검증을 모두 통과했다 |
| `구현` | 코드가 있으나 전체 검증 또는 품질 판정이 남았다 |
| `진행` | 일부만 구현됐다 |
| `대기` | 명세만 확정됐다 |

P0는 배포 차단 조건이다. P1은 대형 업데이트 완료 전에 가능한 한 끝내되, 검증되지 않은 게임 수치를 채워
넣는 것보다 빈 상태와 근거 부족 표시를 우선한다.

| OP-06 | ADR은 기존 이력을 지우지 않고 새 결정으로 대체한다 | P0 | 완료 | 변경 결정마다 새 ADR이 있다 |

## 10. 대형 업데이트 완료 게이트

아래가 모두 만족되기 전에는 전체 리빌드 완료로 표시하지 않는다.

1. 이 문서의 P0가 전부 `완료`이고 각 승인 조건에 재현 가능한 증거가 있다.
2. `npm run verify`가 통과한다.
3. 랜딩·가이드·편집기를 1440px, 768px, 390px에서 직접 열어 본다.
4. 편집기에서 토대·제련기·제작기·분배기·병합기·벨트·리프트를 포함한 복합 공정을 만들고 저장 후 복원한다.
5. SVG/PNG를 직접 열어 자산 프레임, 토대 이음선, 포트 가림, 텍스트 회전, 높이 깊이를 판정한다.
6. 공개 배포 URL에서 서비스워커·새로고침·직접 경로 진입을 검사한다.
