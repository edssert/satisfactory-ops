This article covers the development of  ''[[Satisfactory]]'' from the game's inception to the release of the Closed Alpha.

''Satisfactory'' started development as a game jam game.<ref name="yt-7I3NGAm3j_4@70">[https://youtu.be/7I3NGAm3j_4?t=70 YouTube - Revisiting the FIRST YEAR of dev on Satisfactory (Game Dev Vlog) - Game Jam Game #1]</ref><ref name="yt-7I3NGAm3j_4@515">[https://youtu.be/7I3NGAm3j_4?t=515 YouTube - Revisiting the FIRST YEAR of dev on Satisfactory (Game Dev Vlog) - Game Jam Game #2]</ref><ref name="yt-HUmedz9mghE">[https://www.youtube.com/watch?v=HUmedz9mghE YouTube - March 19, 2024 Livestream - Q&A: How much time did it take to develop a playable concept of Satisfactory initially?]</ref> According to [[Coffee_Stain_Studios#Coffee_Stain_Studios|CSS UI/UX Designer Nathalie Verweij]] the Game Jam Game in 2016 was called "Base Defense" which inspired a new game that eventually became "Satisfactory" in 2018.<ref name="yt-1GH5SZkrv2M@4795">[https://www.youtube.com/watch?v=1GH5SZkrv2M&t=4795s YouTube - Satisfactory 1.0 Release Stream! - Game Jam Game called Base Defense]</ref>

The first year (52 weeks) of game development was done in "sprints" of 2 weeks each<ref group="S1" name="yt-7I3NGAm3j_4@143">[https://www.youtube.com/watch?v=7I3NGAm3j_4&t=143s YouTube - Revisiting the FIRST YEAR of dev on Satisfactory (Game Dev Vlog) - Game Sprints]</ref> with a development team that initially consisted of 16 individuals.<ref group="S1" name="yt-7I3NGAm3j_4@223">[https://www.youtube.com/watch?v=7I3NGAm3j_4&t=223s YouTube - Revisiting the FIRST YEAR of dev on Satisfactory (Game Dev Vlog) - Initial Game Development Team]</ref>

{{Tocright}}

== Early gameplay ==
A lot of the early game systems, like those related to equipment, build gun, building, etc., were based on previous game development in the Sanctum Series.<ref group="S8" name="yt-7I3NGAm3j_4@1112">[https://www.youtube.com/watch?v=7I3NGAm3j_4&t=1112s YouTube - Revisiting the FIRST YEAR of dev on Satisfactory (Game Dev Vlog) - Game Systems Copied From Sanctum]</ref>

Much of the early game allowed you to build and mine anywhere. By Sprint 6 (week 12) this ability was being evaluated, along with looking at the scale and experience of the game to see if that is what they wanted.<ref group="S6" name="yt-7I3NGAm3j_4@1020">[https://www.youtube.com/watch?v=7I3NGAm3j_4&t=1020s YouTube - Revisiting the FIRST YEAR of dev on Satisfactory (Game Dev Vlog) - Early gameplay style decisions]</ref>

In Sprint 12 (week 24), using {{Key|E}} (Interact) outlined the building or machine being interacted with.<ref group="S12" name="yt-7I3NGAm3j_4@1291">[https://www.youtube.com/watch?v=7I3NGAm3j_4&t=1291s YouTube - Revisiting the FIRST YEAR of dev on Satisfactory (Game Dev Vlog) - Use of Key E (Interact)]</ref> Additionally at this time with the introduction of the Portable Miner, combined with the hand-mining ability, the development team began to consider things like how fast or slow should mining be. <ref group="S12" name="yt-7I3NGAm3j_4@1405">[https://www.youtube.com/watch?v=7I3NGAm3j_4&t=1405s YouTube - Revisiting the FIRST YEAR of dev on Satisfactory (Game Dev Vlog) - Portable Miner Introduced]</ref>

In Sprint 20 (week 40) the use of the "build effect" was seen.<ref group="S20" name="yt-7I3NGAm3j_4@1614">[https://www.youtube.com/watch?v=7I3NGAm3j_4&t=1614s YouTube - Revisiting the FIRST YEAR of dev on Satisfactory (Game Dev Vlog) - Assembler - Advanced Constructor]</ref>

Sometime between Sprint 20 and Sprint 23 (week 46) the name of the game of "Satisfactory" was added to Main Menu.<ref group="S23" name="yt-7I3NGAm3j_4@1750">[https://www.youtube.com/watch?v=7I3NGAm3j_4&t=1750s YouTube - Revisiting the FIRST YEAR of dev on Satisfactory (Game Dev Vlog) - Game Initially Called Satisfactory]</ref>

By Sprint 26 (week 52), the individual buildings and production lines looked much like they do now but more "cartoony".<ref group="S26" name="yt-7I3NGAm3j_4@2195">[https://www.youtube.com/watch?v=7I3NGAm3j_4&t=2195s YouTube - Revisiting the FIRST YEAR of dev on Satisfactory (Game Dev Vlog) - Early Game Basic Production Line]</ref><ref group="PA" name="yt-ZW0OOikcWN0@1187">[https://www.youtube.com/watch?v=ZW0OOikcWN0&t=1187s YouTube - Pre-alpha Satisfactory Tutorial (August 2017) - Pre-Alpha Large Factory]</ref>

== [[Biomass]] ==
With the addition of the biomass burner generator after 40 weeks of development came the ability to collect biomass from foliage.<ref group="S20" name="yt-7I3NGAm3j_4@1630">[https://www.youtube.com/watch?v=7I3NGAm3j_4&t=1630s YouTube - Revisiting the FIRST YEAR of dev on Satisfactory (Game Dev Vlog) - Biomass Collection]</ref>

In Sprint 20 (week 40) the ability to collect biomass by using {{Key|E}} was introduced. Collected biomass was used in a biomass burner generator and had an initial Stack Size of 100.

In Sprint 26 (week 52) with more foliage to interact with, there were more places to collect Biomass, to include removing trees without the aid of a chainsaw.<ref group="S26" name="yt-7I3NGAm3j_4@1982"></ref>

By Sprint 12 (week 24) there had been some work on the Pioneer model,<ref group="S12" name="yt-7I3NGAm3j_4@1226">[https://www.youtube.com/watch?v=7I3NGAm3j_4&t=1226s YouTube - Revisiting the FIRST YEAR of dev on Satisfactory (Game Dev Vlog) - Pioneer - Model Development #1]</ref> and by Sprint 26 (week 52) the Pioneer model had received even more improvements.<ref group="S26" name="yt-7I3NGAm3j_4@2163">[https://www.youtube.com/watch?v=7I3NGAm3j_4&t=2163s YouTube - Revisiting the FIRST YEAR of dev on Satisfactory (Game Dev Vlog) - Pioneer - Model Development #2]</ref>

=== Points of view ===
Most of the time in early development the Pioneer used only first person view, but later the ability to use both first and third person views were allowed as part of a test.

In Sprint 20 (week 40) the Pioneer used only third Person view to get more feedback from CSS "players".<ref group="S20" name="yt-7I3NGAm3j_4@1441"></ref>. They did for a while have a way to switch from first person view to third person view.<ref group="S20" name="yt-7I3NGAm3j_4@1469">[https://www.youtube.com/watch?v=7I3NGAm3j_4&t=1469s YouTube - Revisiting the FIRST YEAR of dev on Satisfactory (Game Dev Vlog) - Ability to use both first and third person views]</ref>.

In Sprint 23 (week 46) the Pioneer now used only first person view as part of getting more feedback.<ref group="S23" name="yt-7I3NGAm3j_4@1771">[https://www.youtube.com/watch?v=7I3NGAm3j_4&t=1771s YouTube - Revisiting the FIRST YEAR of dev on Satisfactory (Game Dev Vlog) - Pioneer uses first Person View and Compass Changes]</ref>

In Sprint 26 (week 52) the Pioneer could be switched from first person view and third person view by using the {{Mouse|middle}} (MMB).<ref group="S26" name="yt-7I3NGAm3j_4@2158">[https://www.youtube.com/watch?v=7I3NGAm3j_4&t=2158s YouTube - Revisiting the FIRST YEAR of dev on Satisfactory (Game Dev Vlog) - Pioneer uses 1st Person and 3rd Person Views]</ref><ref group="PA" name="yt-ZW0OOikcWN0@73">[https://www.youtube.com/watch?v=ZW0OOikcWN0&t=73s YouTube - Pre-alpha Satisfactory Tutorial (August 2017) - Pioneer Camera Change]</ref>

=== Health ===
In Sprint 8, when taking damage, like from Poison Gas, you would hear sound effect like someone punching you, and would see blood splatter on the HUD (visor).<ref group="S8" name="yt-7I3NGAm3j_4@1162">[https://www.youtube.com/watch?v=7I3NGAm3j_4&t=1162s YouTube - Revisiting the FIRST YEAR of dev on Satisfactory (Game Dev Vlog) - Poison Gas and Combat]</ref>

Even after 36+ more weeks of development, prior to Closed Alpha, while the "damage" sound was changed, when taking damage, from falling, or Poison Gas, or Creatures, you would still see the blood splatter on the HUD ''(albeit a bit less graphic).''<ref group="PA" name="yt-ZW0OOikcWN0@1296">[https://www.youtube.com/watch?v=ZW0OOikcWN0&t=1296s YouTube - Pre-alpha Satisfactory Tutorial (August 2017) - Damage and Combat Fighting Fluffy-tail Hog]</ref><ref group="PA" name="yt-ZW0OOikcWN0@1364">[https://www.youtube.com/watch?v=ZW0OOikcWN0&t=1364s YouTube - Pre-alpha Satisfactory Tutorial (August 2017) - Damage and Combat Fighting Spitter]</ref><ref group="PA" name="yt-ZW0OOikcWN0@1463">[https://www.youtube.com/watch?v=ZW0OOikcWN0&t=1463s YouTube - Pre-alpha Satisfactory Tutorial (August 2017) - Damage from falling]</ref>

== [[HUD]] ==
The Heads Up Display (HUD) developed as the game developed.

In Sprint 8 (week 16) the HUD saw some major improvements. Some of the changes noted was the use of a Hotbar near the bottom for Build Gun, Pickaxe, and Nail Gun, and a Health Bar located in the upper right.<ref group="S8" name="yt-7I3NGAm3j_4@1162"></ref>

By Sprint 12 (week 24), the Hotbar had been removed, and replaced with a Compass.<ref group="S12" name="yt-7I3NGAm3j_4@1230">[https://www.youtube.com/watch?v=7I3NGAm3j_4&t=1230s YouTube - Revisiting the FIRST YEAR of dev on Satisfactory (Game Dev Vlog) - HUD - Compass]</ref> Activiation of the in-game escape/pause menu would also show an early version of the To-Do List on the left, and current Controls on the right.

By Sprint 23 (week 46) the HUD Compass had been improved but still appeared on the bottom.<ref group="S23" name="yt-7I3NGAm3j_4@1771"></ref> Also during Sprint 23 there was the use of a Health Bar and Stamina Bar.<ref group="S23" name="yt-7I3NGAm3j_4@1811">[https://www.youtube.com/watch?v=7I3NGAm3j_4&t=1811s YouTube - Revisiting the FIRST YEAR of dev on Satisfactory (Game Dev Vlog) - HUD - Health Bar and Stamina Bar]</ref> The Stamina Bar would decrease as you sprinted. The Stamina Bar was removed before Early Access (Update 1) release.

By Sprint 26 (week 52) the Compass had been moved to the top of the HUD.<ref group="S26" name="yt-7I3NGAm3j_4@1982"></ref>

During Pre-Alpha (week 52 and after), the To-Do List could be activated by using {{Key|Left Shift}} while hovering over Build Menu item.<ref group="PA" name="yt-ZW0OOikcWN0@500">[https://www.youtube.com/watch?v=ZW0OOikcWN0&t=500s YouTube - Pre-alpha Satisfactory Tutorial (August 2017) - Example To-Do List Enable]</ref>. The To-Do List would appear in the upper left corner of the HUD.

== [[Game menus]] ==
For most of the first year of game development there were no game menus other than individual menus for Build Gun or buildings.

=== Main menu ===
By Sprint 23 (week 46) the early game started using a Main Menu which included the game name Satisfactory, along with an improved in-game escape/pause menu.<ref group="S23" name="yt-7I3NGAm3j_4@1750"></ref> The Main Menu at this time consisted of:

* Continue (New)
* Play
* Load
* Multiplayer
* Options
* Mods
* Exit

Prior to Closed Alpha the Main Menu defaulted to the Swedish language<ref group="PA" name="yt-ZW0OOikcWN0@24">[https://www.youtube.com/watch?v=ZW0OOikcWN0&t=24s YouTube - Pre-alpha Satisfactory Tutorial (August 2017) - Main Menu Default Language]</ref> but could be changed to local native language by clicking on "Val" (Choice) which opened the game options (settings) menu.

=== Escape menu ===

== [[Inventory]] ==
The display of the Inventory changed as the early game was developed.

At the beginning of game development in Sprint 1 (week 2) the Inventory consisted of just 16 fillable slots in a 4 by 4 grid.<ref group="S1" name="yt-7I3NGAm3j_4@189">[https://www.youtube.com/watch?v=7I3NGAm3j_4&t=189s YouTube - Revisiting the FIRST YEAR of dev on Satisfactory (Game Dev Vlog) - Burnt Bacon Coal Icon]</ref>

By Sprint 12 (week 24) the look of the Inventory dramatically changed with the use of a brown background for inventory items, and the inclusion of Body Slots on top for Hands, Back, and Head.

In Sprint 20 (week 40) the look of the Inventory had changed with removal of brown background and addition of an Equipment Section placed below it with 3 slots for Head, Hands, and Back.

Prior to Closed Alpha, the Inventory pop-up looked the same, but the ability to split items in half by using {{Mouse|right}} (RMB) was seen.<ref group="PA" name="yt-ZW0OOikcWN0@283">[https://youtu.be/ZW0OOikcWN0?t=283s YouTube - Pre-alpha Satisfactory Tutorial (August 2017) - Pioneer Inventory]</ref>

== [[Ping]] ==
Since Sprint 3 the Ping Function {{Key|Alt}} + {{Mouse|left}} (LMB) had been available<ref group="S3" name="yt-7I3NGAm3j_4@1890">[https://www.youtube.com/watch?v=7I3NGAm3j_4&t=1890s YouTube - Revisiting the FIRST YEAR of dev on Satisfactory (Game Dev Vlog) - Ping Function]</ref> and displayed a large "X" on location being pinged instead of the current exclamation point "!" which was however shown in the Compass. The Ping Function was imported from [https://store.steampowered.com/app/91600/Sanctum/ Sanctum], also produced by Coffee Stain Studios.

Prior to Closed Alpha the Ping Function was improved to show a colored diamond ⬙ with bottom half filled in the Compass. A different diamond color could be assigned to each co-op player in a  multiplayer session.<ref group="PA" name="yt-ZW0OOikcWN0@100">[https://www.youtube.com/watch?v=ZW0OOikcWN0&t=100s YouTube - Pre-alpha Satisfactory Tutorial (August 2017) - Ping Function]</ref>

== [[Resource Scanner]] ==
The ability to scan for resources was added early in game development, but illustrated in Sprint 12 (week 24).<ref group="S12" name="yt-7I3NGAm3j_4@1247"></ref> The scan marked nearby resources using small colored laser spikes going up, but did not show there location on the Compass. The color of the spike determined what type of resource it was. Green might have been Stone (Limestone).

In Sprint 26 (week 52), and prior to Closed Alpha, the ability to scan for specific resources was added where by using {{Key|F}} you opened a radial menu and had to pick an item to scan for.<ref group="S26" name="yt-7I3NGAm3j_4@2013">[https://www.youtube.com/watch?v=7I3NGAm3j_4&t=2013s YouTube - Revisiting the FIRST YEAR of dev on Satisfactory (Game Dev Vlog) - Use of Resource Scanner]</ref><ref group="PA" name="yt-ZW0OOikcWN0@155">[https://youtu.be/ZW0OOikcWN0?t=155 YouTube - Pre-alpha Satisfactory Tutorial (August 2017) - Resource Scanner Radial Menu]</ref>

The "scan" graphic effect was changed to be similar to what happens now. After a ping, you would see the location of the specific resource scanned for appear in the Compass (but did not show distance). Individual Resource Nodes was indicated on the Compass by the use of a circle ◯, and a 3-letter abbreviations for Resources, like "IRN" for Iron, "CPR" for Copper" and "STN" for Stone (Limestone).

If close by, during the scan, the Pioneer would see a line flash with each ping and a white marker placed on the Resource Node.<ref group="PA" name="yt-ZW0OOikcWN0@187">[https://youtu.be/ZW0OOikcWN0?t=187 YouTube - Pre-alpha Satisfactory Tutorial (August 2017) - Resource Node Marker]</ref>

==== Market ====
The Trading Post had a "Market" that allowed player to unlock things and progress in the game by selling items and buying upgrades you wanted.<ref group="S12" name="yt-7I3NGAm3j_4@1316">[https://www.youtube.com/watch?v=7I3NGAm3j_4&t=1316s YouTube - Revisiting the FIRST YEAR of dev on Satisfactory (Game Dev Vlog) - Trading Post Purpose]</ref>

Individual Items has a VALUE using a virtual currency of "Rubles", based on currency used in in the [https://store.steampowered.com/app/91600/Sanctum/ Sanctum] game also produced by Coffee Stain Studios, as shown in the following examples:

* Nail Gun (272 Rubles)
* Stone Brick (6 Rubles)
* Wire (1 Ruble)
* Cable (5 Rubles)
* Portable Miner (0 Rubles)
* Standard Cartridge (11 Rubles)
* Fuel (9 Rubles)
* Jetpack (2000 Rubles)

The Trading Post had two Conveyor Input Ports that could be connected to some Production Lines that would allow you to automatically sell items without having to drag them from your inventory.<ref group="S12" name="yt-7I3NGAm3j_4@1375">[https://www.youtube.com/watch?v=7I3NGAm3j_4&t=1375s YouTube - Revisiting the FIRST YEAR of dev on Satisfactory (Game Dev Vlog) - Trading Post Automation]</ref> This was replicated in later game development by use of both the [[AWESOME Sink]] and [[AWESOME Shop]] introduced in Update 3.

The Market had a menu which included the following categories:<ref group="S12" name="yt-7I3NGAm3j_4@1300">[https://www.youtube.com/watch?v=7I3NGAm3j_4&t=1300s YouTube - Revisiting the FIRST YEAR of dev on Satisfactory (Game Dev Vlog) - Trading Post Market Categories]</ref>

==== Tech Onion ====

By Sprint 20 this function had been removed.<ref group="S20" name="yt-7I3NGAm3j_4@1588">[https://www.youtube.com/watch?v=7I3NGAm3j_4&t=1588s YouTube - Revisiting the FIRST YEAR of dev on Satisfactory (Game Dev Vlog) - Tech Onion - Money Removed]</ref>

== [[Craft Bench]] ==
In early game development there was an equivalent to the Craft Bench called a '''Workbench''' which had the description of ''Time to do some manual labor'' when selected in the Build Menu.

In Sprint 6 (week 12) there was a Workbench, accessible from the Build Menu<ref group="S6" name="yt-7I3NGAm3j_4@692">[https://www.youtube.com/watch?v=7I3NGAm3j_4&t=692s YouTube - Revisiting the FIRST YEAR of dev on Satisfactory (Game Dev Vlog) - Workbench (Craft Bench)]</ref> that later became the Craft Bench.

To craft (produce) more advanced items you moved items from inventory to a 3 by 3 grid ''(similar to'' [https://www.minecraft.net/ ''Minecraft'']'')'' and held down {{Key|Space}} key to craft item. This "movement" from Inventory to Workbench Menu was later reevaluated and determined the extra step was not needed, leading to its removal from the game.<ref group="S6" name="yt-7I3NGAm3j_4@738">[https://www.youtube.com/watch?v=7I3NGAm3j_4&t=738s YouTube - Revisiting the FIRST YEAR of dev on Satisfactory (Game Dev Vlog) - Workbench Crafting Procedure Change]</ref>

In Sprint 20 (week 40), the Trading Post came with an early version of the HUB Craft Bench which was called Workbench that looked like an old time forge with fire.<ref group="S20" name="yt-7I3NGAm3j_4@1509">[https://www.youtube.com/watch?v=7I3NGAm3j_4&t=1509s YouTube - Revisiting the FIRST YEAR of dev on Satisfactory (Game Dev Vlog) - Trading Post (HUB) Workbench]</ref> You could also build another free standing Work Bench ''(two words)'' that could be used by the pioneer or another co-op player.

== [[Foundations]] ==
The foundation during game development had only one type and had the description of ''A solid foundation to build on'' when selected in the Build Menu<ref group="S8" name="yt-7I3NGAm3j_4@1101">[https://www.youtube.com/watch?v=7I3NGAm3j_4&t=1101s YouTube - Revisiting the FIRST YEAR of dev on Satisfactory (Game Dev Vlog) - Foundations]</ref> and could be built using 1 Stone Brick.

In Sprint 8 (week 16) the foundation used in the early game was based on similar foundations used in the Sanctum Series.<ref group="S8" name="yt-7I3NGAm3j_4@1112"></ref>

By Sprint 12 (week 24) the look of foundations changed to include the 1 meter "grid" markings.<ref group="S12" name="yt-7I3NGAm3j_4@1298">[https://www.youtube.com/watch?v=7I3NGAm3j_4&t=1298s YouTube - Revisiting the FIRST YEAR of dev on Satisfactory (Game Dev Vlog) - Foundation Improvement #1]</ref>

In Sprint 23 (week 46), 22+ weeks since Sprint 12, the look of foundations had improved and came in five types of thin and thick which are presumed to be the 1 Meter and 2 Meter Foundations, four types had a solid version and a version elevated on "legs", and one type was a special version. Also the Ramp ''(only one type)'' was introduced.<ref group="S23" name="yt-7I3NGAm3j_4@1863"></ref>

In Sprint 26, 6+ weeks since Sprint 23, foundations continued to come in five types as before, but the special version was called Mega Foundation 1a presumed to be 4 normal foundations in one buildable.<ref group="S26" name="yt-7I3NGAm3j_4@2245">[https://www.youtube.com/watch?v=7I3NGAm3j_4&t=2245s YouTube - Revisiting the FIRST YEAR of dev on Satisfactory (Game Dev Vlog) - Use of Foundations]</ref>

In Pre-Alpha foundations had yellow guidelines for placement of walls and other buildable's<ref group="PA" name="yt-ZW0OOikcWN0@1100">[https://www.youtube.com/watch?v=ZW0OOikcWN0?t=1100s YouTube - Pre-alpha Satisfactory Tutorial (August 2017) - Foundations]</ref> and could be built using 2 Cement.

== [[Resource Node]] ==
Resource Nodes were added as the game developed. Early on the look was more like large boulders but eventually were flattened to become what they look like now in game.

In Sprint 1 (week 2) we got the first look at resource nodes, one iron node and one coal node.<ref group="S1" name="yt-7I3NGAm3j_4@146">[https://www.youtube.com/watch?v=7I3NGAm3j_4&t=146s YouTube - Revisiting the FIRST YEAR of dev on Satisfactory (Game Dev Vlog) - Resource Nodes - Iron and Coal]</ref>

By Sprint 6 (week 12), mineable resource nodes had a Purity Percentage of 100%<ref group="S6" name="yt-7I3NGAm3j_4@621">[https://www.youtube.com/watch?v=7I3NGAm3j_4&t=621s YouTube - Revisiting the FIRST YEAR of dev on Satisfactory (Game Dev Vlog) - Pure Resource Node Percentage]</ref> as compared to mining same resource anywhere else (see Resource Deposit - Sprint 6) and the amount of resource nodes in the environment was procedurally generated.<ref group="S6" name="yt-7I3NGAm3j_4@634">[https://www.youtube.com/watch?v=7I3NGAm3j_4&t=634s YouTube - Revisiting the FIRST YEAR of dev on Satisfactory (Game Dev Vlog) - Resource Node Procedurally Generated]</ref>

In Sprint 8 (week 16), mineable resource nodes, in addition to having varied purity levels (impure, normal, pure), also had '''finite resources''' which could be depleted.<ref group="S8" name="yt-7I3NGAm3j_4@1178">[https://www.youtube.com/watch?v=7I3NGAm3j_4&t=1178s YouTube - Revisiting the FIRST YEAR of dev on Satisfactory (Game Dev Vlog) - Resource Node Finite Amounts]</ref> This applied to both when hand mining and when using Miners.

Even in Sprint 26 (week 52) and prior to Closed Alpha, resource nodes continue to have finite resources.<ref group="S26" name="yt-7I3NGAm3j_4@2059">[https://www.youtube.com/watch?v=7I3NGAm3j_4&t=2059s YouTube - Revisiting the FIRST YEAR of dev on Satisfactory (Game Dev Vlog) - Resource Node Finite Amounts]</ref> 

=== Resource deposit ===
In early game development there were no resource deposits (only resource modes), but you did have the ability to mine anywhere for resources.

=== Extraction ===
Ore extraction could be done either by hand mining, or use of a Portable Miner, or full Miner.

In Sprint 6 (week 12) the Pioneer had access to the Pick Axe<ref group="S6" name="yt-7I3NGAm3j_4@583">[https://www.youtube.com/watch?v=7I3NGAm3j_4&t=583s YouTube - Revisiting the FIRST YEAR of dev on Satisfactory (Game Dev Vlog) - Pickaxe (Chisel)]</ref> for hand mining. The Pickaxe later became the Hand Chisel (or Chisel).

With the Pickaxe, after selecting from the Mine Menu shown on the left, you had the ability to hand mine anywhere and not on a specific Resource Deposits or Resource Node. The mining speed (number of hits with Pickaxe) was based on Purity Percentage with higher percentages being able to be hand mined faster (fewer hits) while lower percentages being able to be hand mined slower (more hits).

In Sprint 26 (week 52), like the Workbench during this time, hand mining required you to click for each "mine action" in what was jokingly referred to as the "break your finger version".<ref group="S26" name="yt-7I3NGAm3j_4@2129">[https://www.youtube.com/watch?v=7I3NGAm3j_4&t=2129s YouTube - Revisiting the FIRST YEAR of dev on Satisfactory (Game Dev Vlog) - Resource Node Hand Mining]</ref>

==== Mine list ====
Early on, when equipping the Pickaxe it displayed a Mine List<ref group="S6" name="yt-7I3NGAm3j_4@587">[https://www.youtube.com/watch?v=7I3NGAm3j_4&t=587s YouTube - Revisiting the FIRST YEAR of dev on Satisfactory (Game Dev Vlog) - Pickaxe Mine List]</ref> shown in a box on the upper right which also shows the Purity Percentage for each type of resource available which consisted of:

* Coal.
* Iron.
* Bauxite.
* Copper.
* Stone (Limestone).
* Crude Oil.

==== Hand mining mini-game ====
During early game development the Pioneer could use a hand mining mini-game during which they had to click at just the right time in order to give them greater amounts ''(based on purity)'' then clicking at other times.<ref group="S26" name="yt-7I3NGAm3j_4@2143">[https://www.youtube.com/watch?v=7I3NGAm3j_4&t=2143s YouTube - Revisiting the FIRST YEAR of dev on Satisfactory (Game Dev Vlog) - Resource Node Hand Mining]</ref>

After Sprint 26 but before Closed Alpha, the hand mining mini-game was improved, and only allowed resource extraction by clicking on [PICK] button during a specific time when the arrow was in the blue section which decreased in size with each rotation.<ref group="PA" name="yt-ZW0OOikcWN0@244">[https://www.youtube.com/watch?v=ZW0OOikcWN0&t=244s YouTube - Pre-alpha Satisfactory Tutorial (August 2017) - Resource Hand Mining Mini Game]</ref> This resource hand mining mini-game got faster and faster the longer you hand minded.

The hand mining mini-game was removed in Closed Alpha when it was decided that resource nodes would have infinite amounts regardless of purity level.

== [[Miner]] ==
The Miner was the first buildable created for the game.<ref group="S1" name="yt-7I3NGAm3j_4@162">[https://www.youtube.com/watch?v=7I3NGAm3j_4&t=162s YouTube - Revisiting the FIRST YEAR of dev on Satisfactory (Game Dev Vlog) - First Buildable Developed]</ref>

In Sprint 1 (week 2), the first version of the Miner was a simple block<ref group="S1" name="yt-7I3NGAm3j_4@162"></ref> that could be placed on a Resource Node (Coal or Iron). This version of the Miner also include inventory with the "burnt bacon" Coal Icon.<ref group="S1" name="yt-7I3NGAm3j_4@189">[https://www.youtube.com/watch?v=7I3NGAm3j_4&t=189s YouTube - Revisiting the FIRST YEAR of dev on Satisfactory (Game Dev Vlog) - Burnt Bacon Coal Icon]</ref>

By Sprint 2 (week 4), the second version of the Miner was a vast improvement over the "block" used in Sprint 1, and used a animated unpainted shell that included two conveyor belt output ports.<ref group="S2" name="yt-7I3NGAm3j_4@257">[https://www.youtube.com/watch?v=7I3NGAm3j_4&t=257s YouTube - Revisiting the FIRST YEAR of dev on Satisfactory (Game Dev Vlog) - Miner Improvement #1]</ref>

In Sprint 3 (week 6), the Miner could be selected using the Build Menu. The Miner build hologram could not be rotated, but the Miner could be placed on a Resource Nodes.<ref group="S3" name="yt-7I3NGAm3j_4@358">[https://www.youtube.com/watch?v=7I3NGAm3j_4&t=358s YouTube - Revisiting the FIRST YEAR of dev on Satisfactory (Game Dev Vlog) - Miner Placement on Resource Nodes]</ref> Additionally the Minor saw some graphical improvements to include adding color (green stripe).

In Sprint 6 (week 12) the Miner's model received more improvement by addition of color, could be placed anywhere, not just on Resource Nodes.<ref group="S6" name="yt-7I3NGAm3j_4@782">[https://www.youtube.com/watch?v=7I3NGAm3j_4&t=782s YouTube - Revisiting the FIRST YEAR of dev on Satisfactory (Game Dev Vlog) - Miner Placement Anywhere]</ref> The Miner's placement used a two-step process, {{Mouse|left}} click to place, followed by using {{Mouse|middle}} (Scroll) to rotate into position.<ref group="S6" name="yt-7I3NGAm3j_4@815">[https://www.youtube.com/watch?v=7I3NGAm3j_4&t=815s YouTube - Revisiting the FIRST YEAR of dev on Satisfactory (Game Dev Vlog) - Miner Placement Rotation]</ref> You selected which resource to mine from the Miner's UI.

By Sprint 26 (week 52), and before Closed Alpha, after 40+ more weeks of development, the Miner's model had improved greatly, but still initially looked much different than the current design.<ref group="PA" name="yt-ZW0OOikcWN0@570">[https://www.youtube.com/watch?v=ZW0OOikcWN0&t=570s YouTube - Pre-alpha Satisfactory Tutorial (August 2017) - Miner Improvement #1]</ref> Eventually the Miner's look was changed to be similar to the Mk.1 Miner.<ref group="PA" name="yt-7I3NGAm3j_4@2078">[https://www.youtube.com/watch?v=7I3NGAm3j_4&t=2078s YouTube - Revisiting the FIRST YEAR of dev on Satisfactory (Game Dev Vlog) - Miner Improvement #2]</ref> 

The cost for the Miner was 15 Iron Rods, 12 Iron Plate, 12 Wire.

The Miner's UI was very simple showing only the extractor status, extraction progress bar, and if powered or not.<ref group="PA" name="yt-ZW0OOikcWN0@615">[https://www.youtube.com/watch?v=ZW0OOikcWN0&t=615s YouTube - Pre-alpha Satisfactory Tutorial (August 2017) - Miner Improvement #1 - UI (General)]</ref><ref group="PA" name="yt-ZW0OOikcWN0@732">[https://www.youtube.com/watch?v=ZW0OOikcWN0&t=732s YouTube - Pre-alpha Satisfactory Tutorial (August 2017) - Miner Improvement #1 - UI (Extraction)]</ref>

If not connected to a conveyor belt, the max a Miner could extract was 50 Ore at which point it would stop.<ref group="PA" name="yt-ZW0OOikcWN0@778">[https://www.youtube.com/watch?v=ZW0OOikcWN0&t=778s YouTube - Pre-alpha Satisfactory Tutorial (August 2017) - Miner Improvement #1 - Milestone Unlock]</ref>

== [[Conveyor Belts]] ==
Conveyor belts were added in Sprint 2, and continued to be improved during early development.

In Sprint 2 (week 4) the conveyor belts was nothing more than a block that could be placed in a spline.<ref group="S2" name="yt-7I3NGAm3j_4@273">[https://www.youtube.com/watch?v=7I3NGAm3j_4&t=273s YouTube - Revisiting the FIRST YEAR of dev on Satisfactory (Game Dev Vlog) - Early Conveyor Belt]</ref>

By Sprint 3 (week 6), the conveyor belt started using a animated unpainted shell.<ref group="S3" name="yt-7I3NGAm3j_4@410">[https://www.youtube.com/watch?v=7I3NGAm3j_4&t=410s YouTube - Revisiting the FIRST YEAR of dev on Satisfactory (Game Dev Vlog) - Conveyor Belt Improvement #1]</ref>

In Sprint 6 (week 12) conveyor belts had the description of ''Moves them resources where you want them to go'' when selected in the Build Menu<ref group="S6" name="yt-7I3NGAm3j_4@912">[https://www.youtube.com/watch?v=7I3NGAm3j_4&t=912s YouTube - Revisiting the FIRST YEAR of dev on Satisfactory (Game Dev Vlog) - Conveyor Belt Improvement #2]</ref> and could be built at the cost of 2 Iron Pipes (using burnt bacon icon).

By Sprint 8 (week 16) conveyor belts saw some improvements in both design and placement<ref group="S8" name="yt-7I3NGAm3j_4@1131"></ref> and could be built using only 1 Iron Pipe (now with proper icon)/

By Pre-Alpha, 36 weeks since Sprint 8, the look of conveyor belts had improved significantly<ref group="PA" name="yt-ZW0OOikcWN0@848">[https://www.youtube.com/watch?v=ZW0OOikcWN0&t=848s YouTube - Pre-alpha Satisfactory Tutorial (August 2017) - Conveyor Belt Improvement]</ref> and could now be built using 1 Iron Plate instead of Iron Pipe. The conveyor belts could be dragged from output (or input) to anywhere, along with the ability to build them directly on the ground with an automatic starting conveyor pole.<ref group="PA" name="yt-ZW0OOikcWN0@1014">[https://www.youtube.com/watch?v=ZW0OOikcWN0&t=1014s YouTube - Pre-alpha Satisfactory Tutorial (August 2017) - Conveyor Belt Construction]</ref> Conveyor belts at this time did not have the automatic ending conveyor pole, but free floated in the air.

== [[Conveyor Poles]] ==
Conveyor poles were added in Sprint 6, and during most early game development was very simplistic in design.

In Sprint 6 (week 12) conveyor poles were selectable via the Build Menu<ref group="S6" name="yt-7I3NGAm3j_4@867">[https://www.youtube.com/watch?v=7I3NGAm3j_4&t=867s YouTube - Revisiting the FIRST YEAR of dev on Satisfactory (Game Dev Vlog) - Sprint 6 Conveyor Pole Description]</ref> and had the description of ''Buld conveyors in the air'' (misspelling in menu). Early game conveyor poles consisted of a basic "T" design with a green attachment block and had a cost of 1 Iron Pipe (using burnt bacon icon) and 1 Iron Plate.

In Sprint 8 (week 16), placing conveyor poles on Foundations allowed for better placement<ref group="S8" name="yt-7I3NGAm3j_4@1131">[https://www.youtube.com/watch?v=7I3NGAm3j_4&t=1131s YouTube - Revisiting the FIRST YEAR of dev on Satisfactory (Game Dev Vlog) - Conveyor Pole Placement Improved]</ref> and improved construction of conveyor belts. Conveyor poles still cost 1 Iron Pipe (now with proper icon) and 1 Iron Plate.

By Pre-Alpha, 36 weeks since Sprint 8, the look of conveyor poles had improved significantly<ref group="PA" name="yt-ZW0OOikcWN0@1066">[https://www.youtube.com/watch?v=ZW0OOikcWN0&t=1066s YouTube - Pre-alpha Satisfactory Tutorial (August 2017) - Conveyor Pole Improvement]</ref> and could now be built using 2 Iron Rods, 1 Iron Plate, and 2 Cement. The conveyor belts could be dragged from output (or input) to anywhere, along with the ability to build them directly on the ground with an automatic starting conveyor pole. In addition to the ability to rotate conveyor poles using {{Mouse|middle}}, the conveyor poles could be raised several meters prior to placement of conveyor belts.

== [[Conveyor Splitter]] ==
Early game development had a conveyor splitter in a "Y" configuration with one Input and two Outputs.

In Sprint 3 (week 6) the conveyor Splitter started by dividing input in half.<ref group="S3" name="yt-7I3NGAm3j_4@514">[https://www.youtube.com/watch?v=7I3NGAm3j_4&t=514s YouTube - Revisiting the FIRST YEAR of dev on Satisfactory (Game Dev Vlog) - Conveyor Splitter Hologram]</ref>

In Sprint 6 (week 12) the conveyor splitter had the description of ''Splits stuff'' when selected in the Build Menu<ref group="S6" name="yt-7I3NGAm3j_4@942">[https://youtu.be/7I3NGAm3j_4?t=942s YouTube - Revisiting the FIRST YEAR of dev on Satisfactory (Game Dev Vlog) - Sprint 6 - Conveyor Splitter Build Menu]</ref> and could be built using 3 Iron Pipe and 3 Wire.

In Sprint 23 (week 46), the conveyor splitter graphic mesh and look had drastically changed.<ref group="S23" name="yt-7I3NGAm3j_4@1863"></ref>

== [[Conveyor Merger]] ==
In early game development there was a Conveyor Hub which in reality was a 7:1 conveyor merger.

In Sprint 3 (week 6) the conveyor bub was a buildable that would combine 7 input conveyor belts into 1 output conveyor belt.<ref group="S3" name="yt-7I3NGAm3j_4@420">[https://www.youtube.com/watch?v=7I3NGAm3j_4&t=420s YouTube - Revisiting the FIRST YEAR of dev on Satisfactory (Game Dev Vlog) - Conveyor Hub (Merger)]</ref> Early on the Miner produced less, so the idea was to have multiple Miners connected to a central Conveyor Hub.

In Sprint 6 (week 12) Conveyor Hubs had the description of "Hub that merges 7 conveyor belts" when selected in the Build Menu<ref group="S6" name="yt-7I3NGAm3j_4@942"></ref> and  could be built using 3 Iron Plate and 5 Copper Ingot.

By Sprint 23 (week 46), the conveyor hub still existed, but there was also now a conveyor merger.<ref group="S23" name="yt-7I3NGAm3j_4@1863"></ref>

In Sprint 26 (week 52), the conveyor hub was now called Mega Conveyor Merger and the conveyor merger was called Basic Conveyor Merger.<ref group="S26" name="yt-7I3NGAm3j_4@2214"></ref>

== Manufacturing Plant ==
In early game development there was not a dedicated [[Smelter]], [[Constructor]], or [[Refinery]], but that function was combined in a multi-purpose Manufacturing Plant which had a description of ''Makes basic parts''.

The "function" of the manufacturing plant was determined by the recipe chosen in the menu. What the manufacturing plant was being used for was displayed on the above the output port. The manufacturing plant was sometimes referred to as the "Darth Vader Helmet" building.<ref group="S3" name="yt-7I3NGAm3j_4@495">[https://www.youtube.com/watch?v=7I3NGAm3j_4&t=495s YouTube - Revisiting the FIRST YEAR of dev on Satisfactory (Game Dev Vlog) - Manufacturing Plant = Output Recipe Name and Building Joke Name]</ref>

In Sprint 3 (week 6) the manufacturing plant was introduced and used as a Smelter<ref group="S3" name="yt-7I3NGAm3j_4@450">[https://www.youtube.com/watch?v=7I3NGAm3j_4&t=450s YouTube - Revisiting the FIRST YEAR of dev on Satisfactory (Game Dev Vlog) - Use of Manufacturing Plant (Smelter)]</ref>, but the build cost was unknown ''(reference shows confusing information)''.

By Sprint 6 (week 12) the manufacturing plants "functions" were split into other buildable's with the exception of the constructor which still used the same graphic. The individual "functions" at this time did not have mark levels but ''that'' was being considered.<ref group="S6" name="yt-7I3NGAm3j_4@892">[https://www.youtube.com/watch?v=7I3NGAm3j_4&t=892s YouTube - Revisiting the FIRST YEAR of dev on Satisfactory (Game Dev Vlog) - Manufacturing Plant History]</ref>

== [[Smelter]] ==
In Sprint 6 (week 12) smelters become its own buildable and had the description of ''The long awaited smelter'' when selected in the Build Menu.

Smelters were selectable via the Build Menu, had a black color and looked like a "face", and could be built using 6 Iron Plates and 8 Stone Bricks.<ref group="S6" name="yt-7I3NGAm3j_4@823">[https://www.youtube.com/watch?v=7I3NGAm3j_4&t=823s YouTube - Revisiting the FIRST YEAR of dev on Satisfactory (Game Dev Vlog) - Smelter]</ref> These early Smelters had two Inputs and during production the "mouth" was animated during production.<ref group="S6" name="yt-7I3NGAm3j_4@841">[https://www.youtube.com/watch?v=7I3NGAm3j_4&t=841s YouTube - Revisiting the FIRST YEAR of dev on Satisfactory (Game Dev Vlog) - Smelter Two Inputs]</ref>

In Sprint 26 (week 52) the game still had two types of Smelters<ref group="S26" name="yt-7I3NGAm3j_4@2086">[https://www.youtube.com/watch?v=7I3NGAm3j_4&t=2086s YouTube - Revisiting the FIRST YEAR of dev on Satisfactory (Game Dev Vlog) - Smelter]</ref> which included the standard Basic Smelter and the Mk.2 Smelter (Basic Foundry).<ref group="S26" name="yt-7I3NGAm3j_4@2100">[https://www.youtube.com/watch?v=7I3NGAm3j_4&t=2100s YouTube - Revisiting the FIRST YEAR of dev on Satisfactory (Game Dev Vlog) - Smelter]</ref>

During Pre-Alpha, when building a basic smelter the hologram had one input (green) and one output (orange).<ref group="PA" name="yt-ZW0OOikcWN0@819">[https://www.youtube.com/watch?v=ZW0OOikcWN0&t=819s YouTube - Pre-alpha Satisfactory Tutorial (August 2017) - Basic Smelter Construction]</ref>

The basic smelter UI consisted of two tabs.
* Input and Output - Showed production status consisting of ore being inputed and ingots being outputted. If no conveyor belt was connected to either input or output the appropriate section would display red. Additionally there was a Power Status notification if no power was applied.<ref group="PA" name="yt-ZW0OOikcWN0@873">[https://www.youtube.com/watch?v=ZW0OOikcWN0&t=873s YouTube - Pre-alpha Satisfactory Tutorial (August 2017) - Basic Smelter UI - Input and Output]</ref>
* Recipes - Showed the available recipes to choose from.<ref group="PA" name="yt-ZW0OOikcWN0@969">[https://www.youtube.com/watch?v=ZW0OOikcWN0&t=969s YouTube - Pre-alpha Satisfactory Tutorial (August 2017) - Basic Smelter UI - Input and Output]</ref>

== Wind Turbine ==
Early game development had access to Wind Turbines for power generation. These were eventually abandoned, due to the ability to place anywhere (nothing to deal with), and replaced with the use of [[Geothermal Generator|Geothermal Power Generators]] which are limited to being only used on Geysers.<ref name="yt-WEB9-SgYExg">[https://www.youtube.com/watch?v=WEB9-SgYExg YouTube - August 22nd, 2023 Livestream - Q&A: Will there be energy sources like solar & wind power?]</ref>

In Sprint 3 (week 6) power was supplied by wind turbines which were eventually replaced by Geothermal Generators.<ref group="S3" name="yt-7I3NGAm3j_4@382">[https://www.youtube.com/watch?v=7I3NGAm3j_4&t=382s YouTube - Revisiting the FIRST YEAR of dev on Satisfactory (Game Dev Vlog) - Use of Wind Turbines #1]</ref>

By Sprint 6 (week 12) in addition to Coal Power, the early game still used Wind Turbines.<ref group="S6" name="yt-7I3NGAm3j_4@1049"></ref>

In Sprint 20 (week 40), after 40 weeks of development, wind turbines were removed and replaced by biomass burners.<ref group="S20" name="yt-7I3NGAm3j_4@1621">[https://www.youtube.com/watch?v=7I3NGAm3j_4&t=1621s YouTube - Revisiting the FIRST YEAR of dev on Satisfactory (Game Dev Vlog) - Biomass Burner]</ref>

== [[Power Line]] ==
Early on, Power Lines did not need [[Cable]] to be crafted in order to use, but could be placed as needed.

In Sprint 3 (week 6) the use of Power Lines required aiming and clicking on the Power Connectors on individual Buildings.<ref group="S3" name="yt-7I3NGAm3j_4@393">[https://www.youtube.com/watch?v=7I3NGAm3j_4&t=393s YouTube - Revisiting the FIRST YEAR of dev on Satisfactory (Game Dev Vlog) - Use Power Lines]</ref> Additionally there was the ability to daisy-chain power from building to building.<ref group="S3" name="yt-7I3NGAm3j_4@478">[https://www.youtube.com/watch?v=7I3NGAm3j_4&t=478s YouTube - Revisiting the FIRST YEAR of dev on Satisfactory (Game Dev Vlog) - Use Power Lines - Daisy Chaining]</ref>

By Sprint 20 (week 40) Power Lines still required aiming and clicking on the Power Connectors on individual Buildings, did not require the use of Cable, but when a "connection" between two Power Connectors was made there was a "power up sound" that was also heard.<ref group="S20" name="yt-7I3NGAm3j_4@1653"></ref> The ability to daisy-chain power from building to building was removed with the addition of Power Poles.

In Sprint 26 (week 52) and after, connecting the Power Line would show a large voltage ⚡ symbol above building or machine power connectors</ref><ref group="PA" name="yt-ZW0OOikcWN0@716">[https://www.youtube.com/watch?v=ZW0OOikcWN0&t=716s YouTube - Pre-alpha Satisfactory Tutorial (August 2017) - Connecting Power Line]</ref> and require the use of Cable. After the connection is made the player would hear a bit of static sound.

== [[Tractor]] ==
The Tractor was the second vehicle, after the Truck, that appeared in the game during early development.<ref group="S20" name="yt-7I3NGAm3j_4@1600">[https://www.youtube.com/watch?v=7I3NGAm3j_4&t=1600s YouTube - Revisiting the FIRST YEAR of dev on Satisfactory (Game Dev Vlog) - Vehicles - Tractor]</ref>

In Sprint 20 (week 40) the early version of the Tractor looks much like it does now but when driving it also had "speedometer" showing how fast you were going along with what "gear" you were in. You also saw what grid coordinate you were in ''(displayed below the Speedometer)'' along with an improvement to the compass on the bottom.

By Pre-Alpha, 12+ weeks since Sprint 20, the Tractor improved a little bit.<ref group="PA" name="yt-ZW0OOikcWN0@1238">[https://www.youtube.com/watch?v=ZW0OOikcWN0&t=1238s YouTube - Pre-alpha Satisfactory Tutorial (August 2017) - Vehicles - Tractor Improvement]</ref>.

The Tractor had a Workbench accessible in the back in which you could craft or store items, and also was used to fuel the vehicle.

One of the primary purposes of the Tractor was its use while exploring the world. While manually driving the Tractor, on the left of the HUD, was shown fuel status and use along with current speed in kilometers per hour (KMH), and vehicle damage status (health).

While driving the Tractor the Pioneer could not get hurt from hostile indigenous lifeforms.<ref group="PA" name="yt-ZW0OOikcWN0@1296"></ref>.

== Closed Alpha Prototypes ==
Prior to release of [[Alpha Test Weekend]] there were several areas where prototypes were tested. With few exceptions, most of these were removed and never made it into the [[Patch 0.1|Update 1 (Early Access)]].

=== World ===
In Closed Alpha there were several world related prototype events, flora, and weather that were tested.

==== Events ====
* There was an indication that the developers were testing the idea that the [[Pioneer]] could get '''Drowning Damage'''.<ref group="Alpha" name="yt-3ktJY78H018@972">[https://www.youtube.com/watch?v=3ktJY78H018&t=972s YouTube - We Found Coffee Stain's Secret Developer Map in Satisfactory - Pioneer Drowning Damage]</ref> This was never implemented in game due to the games development shift away from any aquatic related gameplay other than swimming.
* There was also something called '''Earthquake Manager''' that was used to trigger rock slides.<ref group="Alpha" name="yt-3ktJY78H018@1000">[https://www.youtube.com/watch?v=3ktJY78H018&t=1000s YouTube - We Found Coffee Stain's Secret Developer Map in Satisfactory - Earthquake Manager and Rock Slides]</ref> This was never implemented in game most likely due to the work involved related to "rolling rocks" and game performance.

==== Flora ====
During Closed Alpha various type of flora were tested and with one exception these prototype creatures never made in to the game.

===== Jungle Tree =====
There was indication that a prototype form of jungle tree with vines and falling leaves you could ride on.<ref group="Alpha" name="yt-3ktJY78H018@1029">[https://www.youtube.com/watch?v=3ktJY78H018&t=1029s YouTube - We Found Coffee Stain's Secret Developer Map in Satisfactory - Prototype Jungle Tree]</ref> These perhaps inspired in part the [[Vine ladder]]s that you could find in certain locations prior to [[Patch 1.0|Version 1.0]] when they were removed. The Jungle Tree vines and ridable falling leaves were never added to the game.

There was an Assault Rifle that came in two variants that used cartridges, a Mk.1 that had two shots, and a Mk.2 that had 4 shots.<ref group="Alpha" name="yt-3ktJY78H018@273">[https://www.youtube.com/watch?v=3ktJY78H018&t=273s YouTube - We Found Coffee Stain's Secret Developer Map in Satisfactory - Prototype Equipment - Assault Rifle]</ref> These eventually became the [[Rifle]] and [[Rifle Mk.2]], however the Rifle Mk.2 was eventually removed in [[Patch 0.1.6 build 98445|Update 1]].
* TRIVIA: The inventory icon for the Assault Rifle Mk.2 variant show a picture of [[Coffee_Stain_Studios#Coffee_Stain_Studios|Simon Begby - Coffee Stain Studios VFX Artist]].

File:Closed Alpha Prototype Equipment - Assault Rifle Inventory.png|Closed Alpha Prototype Equipment - Assault Rifle Mk.2 Inventory
</gallery>

==== Machine Gun ====
There was a Machine Gun that used cartridges that had 100 shots.<ref group="Alpha" name="yt-3ktJY78H018@291">[https://www.youtube.com/watch?v=3ktJY78H018&t=291s YouTube - We Found Coffee Stain's Secret Developer Map in Satisfactory - Prototype Equipment - Machine Gun]</ref> This weapon was very bulky and so over powered that it ruined the "exploration aspect" of the game, and for that reason it was removed from the game. It return in [[Patch 0.6.0.0|Update 6]] in the form of [[Turbo Rifle Ammo]].

==== Rebar Scatter Gun ====
{{MainSub|Old_unreleased_content#Rebar_Scatter_Gun|0}}
There was a Rebar Scatter Gun tested in Closed Alpha that used Spiked Rebar Ammo to shoot multiple spikes in a scattered pattern.<ref group="Alpha" name="yt-3ktJY78H018@327">[https://www.youtube.com/watch?v=3ktJY78H018&t=327s YouTube - We Found Coffee Stain's Secret Developer Map in Satisfactory - Prototype Equipment - Rebar Scatter Gun]</ref> The Rebar Scatter Gun was eventually removed in [[Patch 0.1.6 build 98445|Update 1]] and return in [[Patch 0.6.0.0|Update 6]] in the form of [[Rebar_Gun#Shatter-0|Shatter Rebar Ammo]].

==== Eagle Eye Drone ====
There was mention of a Eagle Eye Drone in Closed Alpha.<ref group="Alpha" name="yt-3ktJY78H018@363">[https://www.youtube.com/watch?v=3ktJY78H018&t=363s YouTube - We Found Coffee Stain's Secret Developer Map in Satisfactory - Prototype Equipment - Eagle Eye Drone]</ref>. === Buildings ===
{{Main|Old unreleased content}}
During Closed Alpha several buildable's were prototyped and tested, with most either removed, or eventually making it into the game in a different form.

==== Walls ====
In Closed Alpha there were several Wall types that had decorations.<ref group="Alpha" name="yt-3ktJY78H018@530">[https://www.youtube.com/watch?v=3ktJY78H018&t=530s YouTube - We Found Coffee Stain's Secret Developer Map in Satisfactory - Walls]</ref> Due to the repetitive nature when placing several decorated walls one after another, these early wall type version were removed in favor of [[Walls#Types|blank wall types]] upon which you could add your own decorations.

<gallery>
File:Closed Alpha Walls.png|Early version of Walls showing use of various decorations
</gallery>

==== Foundations and Floors ====
The development of Foundations continued in Closed Alpha which had regular and large size foundations, to also include some ''thin versions'' that could be added to foundations for textures.<ref group="Alpha" name="yt-3ktJY78H018@572">[https://www.youtube.com/watch?v=3ktJY78H018&t=572s YouTube - We Found Coffee Stain's Secret Developer Map in Satisfactory - Foundations]</ref>
* See also: [[Early_game_development#Foundations| Early game development > Foundations]]

==== Foundation Stair ====
Closed Alpha featured a version of [[Foundations#Stairs|Foundation Stairs]] that included a railing. While the foundation stairs remained in the game until [[Patch 1.0|Version 1.0]] the railing was removed prior to [[Patch 0.1|Update 1 (Early Access)]].
* See also: [[Early_game_development#Stair| Early game development > Stair]]

==== Variants ====
