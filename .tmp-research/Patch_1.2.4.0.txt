== Intro ==
Hi Pioneers!

Hello everyone! 

It’s been a while since the last patch and people around our studio have been on vacation at different times during summer, and through the vacation period we’ve been working on some fixes for you all.

Now that we’re mostly back it was time to gather them all and get them out for you to enjoy 🙂

This update will be available on all available platforms as it has been the case with 1.2 onwards, so you can enjoy it on Steam/Epic, Xbox Series S|X and PlayStation 5

We had some leftover issues from 1.2 that we wanted to address which are finally fixed in this patch, but if there’s something else you think we should still take a look at please let us know over at our QA Site https://questions.satisfactorygame.com/ We really appreciate your feedback

We’ll continue working on making Satisfactory even more enjoyable for everyone

Thank you for all your support ❤️

==New==
* [[Settings#Video|First Person FOV Modifier Equipment Scale]] can now once again be set to more values (0.5 to 2)

==Audio==
* Fixed the [[The_HUB#FICSIT_Freighter|FICSIT Freighter in the HUB]] having an unintentionally silent takeoff in multiple scenarios when standing in or around the HUB
* Fixed [[Photo Mode]] SFX being audible for all players in [[Multiplayer]]

==Bug Fixes==
* Fixed situations in Multiplayer where you would be unable to move after riding inside a Self-Driving [[Vehicles|vehicle]] after a while
* Fixed multiple instances where Profanity Filtering was not correctly applying or only applying after closing a UI
* Fixed a crash related to <code>AFGRainAudioSubsystem</code>
* Improvements to situations where players would be stuck on loading screens when trying to join another player hosting in Multiplayer, the player joining now should properly load in more consistently
* Fixed [[Beams]] required materials to build being higher than intended
* Fixed some log spam when [[Resource Scanner|scanning for resources]] or [[Ping|pinging]] in-game
* Fixed [[Splitter]]/[[Merger]]s holograms that were locked via [[Build_Gun#Hologram_lock_and_nudge_mode|nudging]], resetting their locked position when hovering over a [[Conveyor Lifts|Conveyor Lift]]
* Fixed [[Conveyor Belts]] not properly building straight after previously building a segment with a 90 degree bend while using Straight belt build mode
* Fixed situations where[[Dedicated servers|Dedicated Server Admin]] access would constantly be lost and owners would have to re-authenticate every time
* Fixed [[Settings#Video|Screen Percentage]] setting not correctly working
* Fixed [[Blueprints]] not correctly showing up in Categories in a few scenarios, including Multiplayer
* Fixed a Crash when leaving a multiplayer session while inside a vehicle
* Fixed Online Session settings not changing while in-game, and session not correctly restarting when doing so
* Fixed Blueprints not working if the [[New_game#Session_name|session name]] contains invalid characters
* Fixed being unable to switch to the middle track on a 3 -way [[Railroad Switch Control|Railway switch]] setup when driving a [[Electric Locomotive|Locomotive]]
* Fixed session names being blurred unintentionally on Dedicated Server
* Fixed a few [[game menus|menus]] having unintended behaviors when double clicking a save
* Fixed sampled [[Pipelines]] not retaining [[Customizer|customizer colors]] on the Flow Indicators
* Fixed Blueprints containing [[Vehicle Paths]] that were not built properly centered in a [[Blueprint Designer]] having misaligned auto-connect holograms indicators when trying to build them
* Fixed sampled customization settings not applying to [[Pipeline Supports]]
* Fixed [[Personnel Elevator]] not being vertically aligned to floor stops
* Fixed a crash related to <code>FInstanceSceneDataBuffers</code>
* Fixed one of the most frequent crashes on PS5 related to <code>UFGBlueprintFunctionLibrary</code>
* Fixed an issue where players could end up with invisible [[Signs|Sign poles]] with lingering collision that could not be interacted with in some scenarios
* Fixed [[Gate Hole Wall|Gates]] preventing Vehicle paths from being built through them
* Fixed a Crash that happened when building a Personnel Elevator as a part of a Blueprint
* Fixed an unintentional change in behavior for Hologram snapping, Hologram snapping (CTRL/Automatic Clearance Separation) should now behave like it did in Update 1.1
* Fixed a crash in Multiplayer related to <code>FInstanceSceneDataBuffers</code>
* Fixed Blueprint Dismantling not showing refunded parts in Multiplayer
* Fixed Autopilot status rapidly flickering in the Vehicle Path Menu when vehicles are waiting in traffic
* Fixed available item amounts in the [[Dimensional Depot Uploader|Dimensional Depot]] not properly updating while hand crafting items
* Fixed previously placed Blueprints becoming invisible in multiplayer when rejoining a session in some scenarios
* Fixed [[Object Scanner]] occasionally misleading to previously picked up rewards in Multiplayer
* Fixed [[Singularity Cell|Singularity Cells Icons]] placed inside a [[Portal]] becoming invalid and having numbers overlapping after opening and closing the menu
* Fixed [[Valve|Valve Holograms]] unintentionally reopening the Build Menu when pressing right click after completing the first placement step, instead of cancelling the step
* Fixed Crash related to <code>URainOcclusionWorldSubsystem</code>
* Fixed [[Customizer]] setting not applying on [[Conveyor Belts]] or [[Pipelines]] when using [[Blueprint#Auto-connect|blueprint auto-connect]]
* Fixed Railroad Signals sometimes not being able to switch directions
* Fixed interaction outlines getting stuck when entering a Vehicle in Multiplayer

==Optimization==
* Improved the way we handle clearance overlap checks, so hovering Holograms on top of other Buildables should no longer produce constant stutters and framerate spikes and be more consistent instead

==UI==
* Fixed opening the tooltip of a [[MAM|MAM research]] while already starting a research resulting in a softlock
* Updated [[Freight Car]] description with correct liquid volume capacity

==Localization==
* Fixed a few errors/untranslated lines in the [[Settings|Options Menu]], [[New_game#Multiplayer_settings|Session Type Warnings]] and [[Fluid Freight Platform]]
* Updated all languages with the latest translations
