== Usage ==
[[Buildings]] ''(other than indicated below)'' can be freely placed within the Blueprint Designer's boundary, essentially treat the blueprint floor as a platform surface. Afterwards, the arrangement can be saved as a blueprint by interacting with the Designer. Buildings placed within the Blueprint Designer can be quickly dismantled from the Designer's UI, placing the returned materials into an attached storage box.

===Blueprint Build Menu===
* Once built, other Blueprints can be placed in the Blueprint Designer from a tab in the [[Build Gun|build menu]] when building a New Blueprint.
** Pillars can partially intersect the edges of the Blueprint Designer.
* The Blueprint Build Menu comes with a Default "Undefined Category" that all new Blueprints Modules will be saved to unless explicitly specified during Blueprint Save Process. <ref name="yt-9KBQyjy-a6g-1">[https://youtu.be/9KBQyjy-a6g?t=468 YouTube - What does the NEW machine do in Satisfactory? - Blueprint Build Menu]</ref>
* During the Blueprint Save Process additional Blueprint Menu Categories and Sub-Categories can be added as desired.
* Using the Blueprint Build Menu, and by clicking the '''+''' icon that appears when you mouse over a desired blueprint, you can add a Blueprint to the [[To-Do List]].

==Blueprint Designer Control Bench==
The Blueprint Designer Control Bench acts as the "front" of the Blueprint.<ref name="yt-ZDN_b6TX5gg@257">[https://www.youtube.com/watch?v=ZDN_b6TX5gg&t=257s YouTube - NEW Blueprint features doctors dont want you to know about - Front of Blueprint]</ref> 

===User Interface===
* The Blueprint Designer Control Bench UI has fields to enter data related to: <ref name="yt-9KBQyjy-a6g-2">[https://youtu.be/9KBQyjy-a6g?t=426 YouTube - What does the NEW machine do in Satisfactory? - Blueprint Designer Control Bench UI]</ref>
** '''Blueprint Module Name'''.
** '''Blueprint Description'''.
** '''Directory''' - Category / Sub-Category in Build Menu where Blueprint Module will show up.
** Icon Settings for: 
*** '''Icon''' to be used for this Blueprint Module.
*** '''Background Color''' to be used for Icon.
* NOTE: Blueprint Categories and Sub-Categories are part of the Save Game.<ref name="yt-CREPrQ23Dt4-1">[https://youtu.be/CREPrQ23Dt4?t=5375 YouTube - Blueprint Categories and Sub-Categories - Update 7 Experimental Release Live Stream - November 15, 2022]</ref>

===Storage Box===
* The Blueprint Designer has a '''Blueprint Storage Box''' located on the Blueprint Designer Control Bench. <ref name="yt-CREPrQ23Dt4-2">[https://youtu.be/CREPrQ23Dt4?t=4595 YouTube - Blueprint Storage Box - Update 7 Experimental Release Live Stream - November 15, 2022]</ref>
* The Pioneer can add items to and remove items from the Blueprint Storage Box.
* When loading a Blueprint Module the Blueprint Designer will:
** First look in the Blueprint Storage Box for the required materials.
** If the Blueprint Storage Box does not have enough of the required materials the Pioneer's Personal Inventory is then checked.
*** The Pioneer must have required materials in their personal inventory when placing items to create new blueprints<ref name="Q&A - 67f7d3246b7c5731963660e0">[https://questions.satisfactorygame.com/post/67f7d3246b7c5731963660e0 Satisfactory Q&A Post - Blueprint Designer Inventory Bug]</ref>
* When editing a Blueprint Module and a part of a Blueprint is dismantled the Blueprint Designer will:
** First try to place the materials in the Blueprint Storage Box.
** If the Blueprint Storage Box is full then the materials are placed in the Pioneer's Personal Inventory.
** In the event both the Blueprint Storage Box AND the Pioneer's Personal Inventory are full then an [[Crate|Overflow Crate]] is created and placed near the Blueprint Designer Control Bench.

==Tips==
* Can be used to create curved sections of Foundations which eases the z-fighting.
* Can be used to create blueprints of floating structures, such as floating Ceiling Mounted Wall Outlets.

==Trivia==
* The platform of the Designer is 1 meter tall and the frame extends an additional meter above the top of the Designer, making the total height 34 meters.
* Despite having a terminal in its model, the Blueprint Designer can be interacted with from any angle.
